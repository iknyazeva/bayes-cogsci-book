# Ordered Logistic Regression (Likert Scales)

## 1. Why Ordered Categorical Data Violate Standard Models

In cognitive science and psychological testing, responses are frequently recorded on **ordered discrete scales** (e.g., 5-point or 7-point Likert ratings: *Strongly Disagree, Disagree, Neutral, Agree, Strongly Agree*).

Treating ordered categories as continuous numbers (e.g., $1, 2, 3, 4, 5$) in a standard Gaussian linear regression makes two deeply flawed assumptions:
1. **Metric Equality**: It assumes the psychological distance from *Strongly Disagree (1)* to *Disagree (2)* is mathematically identical to the distance from *Neutral (3)* to *Agree (4)*.
2. **Boundary Violations**: Continuous models predict impossible values like $0.4$ or $5.8$.

**Ordered Logistic Regression** (Cumulative Logit Model; McElreath, *Statistical Rethinking* Ch. 12) treats categories as discrete bins carved out of an underlying **continuous latent psychological scale** by ordered **cutpoints (thresholds)**.

```
       Latent Psychological Continuum (z = βx + ε)
  <────────┼──────────────┼──────────────┼──────────────┼────────>
          c₁             c₂             c₃             c₄
      Category 1     Category 2     Category 3     Category 4   Category 5
    (Strong Disagree) (Disagree)     (Neutral)       (Agree)  (Strong Agree)
```

## 2. Mathematical Architecture: The Cumulative Logit

For an ordered outcome with $K$ categories, there are $K - 1$ ordered cutpoint parameters:

$$
c_1 < c_2 < \dots < c_{K-1}
$$

The probability that an individual's response falls at or below category $k$ is given by the **cumulative logit**:

$$
\operatorname{logit}(P(y_i \le k \mid x_i)) = c_k - \beta x_i \implies P(y_i \le k \mid x_i) = \frac{1}{1 + e^{-(c_k - \beta x_i)}}
$$

The individual category probabilities $p_k = P(y_i = k \mid x_i)$ are obtained by subtracting adjacent cumulative probabilities:

$$
\begin{aligned}
P(y_i = 1) &= P(y_i \le 1) \\
P(y_i = 2) &= P(y_i \le 2) - P(y_i \le 1) \\
&\;\;\vdots \\
P(y_i = K) &= 1 - P(y_i \le K-1)
\end{aligned}
$$

## 3. Forward Data Simulation and PyMC Implementation

We simulate $N = 120$ participants responding to a 5-point moral judgment scenario as a function of an experimental treatment $x \in [-2, 2]$:

```python
import numpy as np
import pymc as pm
import pytensor.tensor as pt
import arviz as az

# 1. Forward Simulation of 5-Point Likert Responses
np.random.seed(42)
N = 120
x_sim = np.random.uniform(-2, 2, N)

true_cutpoints = np.array([-1.8, -0.6, 0.7, 1.9])
true_beta = 1.0

# Compute cumulative probabilities for each individual
cum_p = 1.0 / (1.0 + np.exp(-(true_cutpoints[:, None] - true_beta * x_sim[None, :]))) # shape (4, N)
# Compute category probabilities
p_cats = np.zeros((5, N))
p_cats[0] = cum_p[0]
p_cats[1] = cum_p[1] - cum_p[0]
p_cats[2] = cum_p[2] - cum_p[1]
p_cats[3] = cum_p[3] - cum_p[2]
p_cats[4] = 1.0 - cum_p[3]

# Sample discrete observations y in {0, 1, 2, 3, 4}
y_sim = np.array([np.random.choice(5, p=p_cats[:, i]) for i in range(N)])

# 2. PyMC Model with Ordered Cutpoints
with pm.Model() as ordered_model:
    # Prior on slope
    beta = pm.Normal("beta", mu=0.0, sigma=1.5)
    
    # Prior on ordered cutpoints using an ordered transformation or normal increments
    # A standard Dirichlet prior on category probabilities at baseline x=0
    cutpoints = pm.Normal(
        "cutpoints", 
        mu=np.array([-2.0, -0.7, 0.7, 2.0]), 
        sigma=1.0, 
        transform=pm.distributions.transforms.ordered,
        initval=np.array([-1.8, -0.6, 0.7, 1.9])
    )
    
    # Linear predictor: eta = beta * x
    eta = beta * x_sim
    
    # OrderedLogistic Likelihood
    y_obs = pm.OrderedLogistic("y_obs", eta=eta, cutpoints=cutpoints, observed=y_sim)
    
    idata_ordered = pm.sample(draws=2000, tune=1000, target_accept=0.95)

az.summary(idata_ordered, var_names=["beta", "cutpoints"])
```

## 4. Substantive Interpretation of Ordered Coefficients

- **The Subtraction Sign ($\text{logit} = c_k - \beta x$)**: Notice the minus sign before $\beta x$. When $\beta > 0$, an increase in $x$ **decreases the cumulative probability** $P(y \le k)$, which means probability mass is shifted **toward higher response categories** (e.g., from *Disagree* toward *Agree*).
- **Non-Linear Response Dynamics**: A 1-unit change in $x$ may strongly affect the probability of moving from category 3 to 4, while having virtually no impact on category 1 if cutpoints are spaced widely apart. Always evaluate predictions as **observable category bar charts** across different values of $x$.

---

## Key Takeaways

- Never treat Likert rating scales as continuous Gaussian outcomes; use an **Ordered Logistic model**.
- The model estimates both the **regression slope $\beta$** (shifting latent mass) and the **threshold cutpoints $c_k$** (defining psychological category boundaries).
- Category probabilities $P(y = k)$ are derived by differencing adjacent cumulative logistic curves.
