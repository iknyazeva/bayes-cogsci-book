> **Organizing Question:** Is the fitted model computationally trustworthy and scientifically adequate, and—only then—how should plausible candidates be compared for a declared prediction task?

Statistical modeling is not an automated tournament where software spits out an arbitrary winner. A Bayesian analysis proceeds through a strict **hierarchy of decision gates**:
1. **Computational Gate**: Were posterior expectations estimated reliably without MCMC pathologies?
2. **Absolute Adequacy (PPC)**: Does the fitted model reproduce scientifically critical features of the observed data?
3. **Comparative Prediction (PSIS-LOO)**: For an explicitly declared held-out unit (new trial, new participant, or future time), which admissible candidate predicts unseen data best?
4. **Substantive Stability**: Do primary scientific estimands remain stable across defensible models?


## 1. The Three Distinct Classes of Model Failure

A core failure in empirical modeling is conflating different types of errors. When an analysis goes wrong, researchers must isolate the failure to one of three distinct classes:

| Failure Class | Diagnostic Evidence | What It Means | Required Remedy |
|---|---|---|---|
| **1. Computational Pathology** | Divergences $> 0$, $\widehat{R} > 1.01$, $\text{ESS} < 400$, low E-BFMI | MCMC failed to explore the geometry; posterior samples are invalid | Reparameterize (non-centered form), tighten priors, tune sampler; **do not interpret** |
| **2. Absolute Model Misfit** | PPC test statistic $T(y) \ll T(y^{\text{rep}})$ (extreme Bayesian $p$-values) | The likelihood or link cannot generate observed features (tails, zeros) | Revise the data-generating structure (e.g. Student-$t$, hurdle, hierarchy) |
| **3. Comparative Prediction Deficit** | $\Delta \text{ELPD} < 0$ with $\text{SE} > |\Delta \text{ELPD}|$ | A candidate does not generalize as well to declared unseen units | Choose simpler model, expand parameterization, or use model stacking |

```{important}
**PPC and LOO are Not Interchangeable:**
- **PPC asks**: *Where does my model systematically contradict empirical reality?* (Absolute adequacy).
- **PSIS-LOO asks**: *Given two flawed models, which one predicts held-out data better?* (Relative performance).
A model can rank #1 in a cross-validation table while still failing a crucial posterior predictive check (e.g., generating impossible negative reaction times)!
```

| **Expected Output** | Difference in expected log predictive density ($\Delta \text{ELPD}$) with standard error |

## 3. Pareto-Smoothed Importance Sampling LOO (PSIS-LOO)

Leave-one-out cross-validation evaluates how well a model trained on $N - 1$ points predicts the held-out point $y_i$:

$$
\text{ELPD}_{\text{loo}} = \sum_{i=1}^N \log p(y_i \mid y_{-i})
$$

Refitting the model $N$ separate times is computationally prohibitive. **PSIS-LOO** (Vehtari, Gelman, & Gabry, 2017) computes this in seconds from a single MCMC run using importance weights smoothed by a generalized Pareto distribution.

```python
import arviz as az

# Compute LOO for both models
loo_additive = az.loo(idata_additive, pointwise=True)
loo_inter = az.loo(idata_inter, pointwise=True)

# Formal model comparison table
comp_df = az.compare({"Additive": idata_additive, "Interaction": idata_inter}, ic="loo")
print(comp_df[["elpd_loo", "p_loo", "elpd_diff", "se", "weight"]])
```

### Reading the Comparison Table:
1. **`elpd_diff`**: Difference in expected log predictive density relative to the top-ranked model.
2. **`se`**: Standard error of the difference. If $|\Delta \text{ELPD}| < 2 \times \text{SE}$, out-of-sample predictive performance is statistically indistinguishable.
3. **`p_loo`**: Effective number of parameters. If $p_{\text{loo}} \gg p$, the model is severely overfitting.
4. **`weight`**: Stacking weights for optimal predictive combination.

### The Pareto $k$ Diagnostic:
ArviZ reports shape parameter $k$ for each observation:
- $k < 0.5$: Excellent reliability; importance weights have finite variance.
- $0.5 \le k \le 0.7$: Acceptable reliability.
- $k > 0.7$: High leverage or outlier point; importance weights have infinite variance. You must run exact K-fold cross-validation or refit without point $i$.

## 4. Aligning the Validation Partition with the Prediction Target

The cross-validation unit must strictly reflect what will be **unseen** in actual application:

| Substantive Question | Validation Split Unit | Method |
|---|---|---|
| Predicting another trial from the *same* participants | Leave-one-trial-out | Standard PSIS-LOO |
| Generalizing to a *new, unseen human participant* | Leave-one-group-out (LOGO) | Group K-fold holding out entire participants |
| Generalizing to a *new stimulus / item* | Leave-one-item-out | Group K-fold holding out stimuli |
| Forecasting *future time periods* | Forward rolling-window | Time-series cross-validation |

Evaluating hierarchical models with standard trial-level LOO dramatically overstates predictive accuracy if the goal is generalizing to new individuals!

## 5. Protocol Milestone: Diagnostics & Validation Plan

Add the following section to your cumulative research protocol:

1. **Computational Gate Verification**: Document 0 divergences, split $\widehat{R} \le 1.01$, and bulk/tail $\text{ESS} \ge 400$ for all primary estimands.
2. **Targeted PPC Discrepancies**: Name the test statistics $T(y)$ selected to audit model boundaries and state the observed vs. replicated Bayesian $p$-values.
3. **Declared Held-Out Unit**: State whether the prediction target is a new observation, participant, item, or site.
4. **Predictive Comparison Table**: Report $\Delta \text{ELPD}$ with standard errors, effective parameters $p_{\text{loo}}$, and Pareto $k$ diagnostics.
5. **Decision Justification**: State whether you select a single model, expand the parameterization, adopt model stacking weights, or retain sensitivity models.

````{dropdown} Concept Check: The "Best of Bad Models" Trap
Suppose Model A has an $\text{ELPD}$ that is $15$ points higher than Model B ($\Delta \text{ELPD} = 15 \pm 3.2$). Can you conclude that Model A is scientifically adequate?

**Answer.** No. Cross-validation is purely relative: Model A is only better than Model B. If both models assume a Gaussian likelihood for bounded positive reaction times with extreme outliers, both models may generate impossible negative predictions and fail replicated minimum PPCs. A model must pass absolute adequacy checks before its relative predictive superiority is meaningful.
````

## Key Takeaways

- Adhere to the **decision ladder**: Computation Gate $\to$ PPC Absolute Adequacy $\to$ PSIS-LOO Relative Comparison.
- High cross-validation ranking does not guarantee absolute model validity.
- Always inspect **Pareto $k$ shape diagnostics**; points with $k > 0.7$ indicate influential outliers requiring exact K-fold refitting.
- Align cross-validation partitions with the substantive target of prediction (trials vs. participants vs. future time).
