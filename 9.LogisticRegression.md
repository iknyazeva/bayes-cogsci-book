# Binary Logistic Regression

## 1. The Generative Model for Binary Outcomes

When the outcome variable is binary ($y_i \in \{0, 1\}$, such as decision choice, task success, or memory recall), standard linear regression fails because:
1. Linear lines produce predicted probabilities outside the valid interval $[0, 1]$ (e.g., $\hat{y} = -0.3$ or $\hat{y} = 1.4$).
2. Residual errors are heteroskedastic ($\operatorname{Var}(y \mid p) = p(1-p)$) and non-normal.

Logistic regression maps the unbounded linear predictor $\eta_i = \alpha + \beta x_i \in (-\infty, \infty)$ to the bounded probability interval $p_i \in [0, 1]$ via the **logistic sigmoid function** (inverse logit):

$$
y_i \sim \operatorname{Bernoulli}(p_i), \quad p_i = \operatorname{logit}^{-1}(\eta_i) = \frac{1}{1 + e^{-(\alpha + \beta x_i)}}
$$

```
                   Forward Generative Workflow:
                   
  Predictor (x) ──► [ Linear: η = α + βx ] ──► [ Sigmoid: p = logit⁻¹(η) ] ──► [ Bernoulli: y ∈ {0, 1} ]
```

## 2. Forward Data Simulation and PyMC Implementation

Before estimating models on empirical data, we simulate $N = 80$ binary responses to test parameter recovery:

```python
import numpy as np
import pymc as pm
import arviz as az

# 1. Forward Simulation of Observable Binary Data
np.random.seed(42)
N = 80
x_sim = np.random.uniform(-3, 3, N)

alpha_true = -0.5
beta_true = 1.2
p_true = 1.0 / (1.0 + np.exp(-(alpha_true + beta_true * x_sim)))
y_sim = np.random.binomial(n=1, p=p_true)

# 2. Bayesian Model in PyMC
with pm.Model() as logistic_model:
    # Scale-aware Priors (avoid excessively wide priors that cause bimodal probabilities)
    alpha = pm.Normal("alpha", mu=0.0, sigma=1.5)
    beta = pm.Normal("beta", mu=0.0, sigma=1.5)
    
    # Linear predictor and deterministic transformations
    eta = alpha + beta * x_sim
    p = pm.Deterministic("p", pm.math.invlogit(eta))
    
    # Odds ratio and Divide-by-4 probability contrast
    odds_ratio = pm.Deterministic("odds_ratio", pm.math.exp(beta))
    max_prob_slope = pm.Deterministic("max_prob_slope", beta / 4.0)
    
    # Likelihood
    y_obs = pm.Bernoulli("y_obs", p=p, observed=y_sim)
    
    idata_logit = pm.sample(draws=2000, tune=1000, target_accept=0.95)

# Summarize posterior
az.summary(idata_logit, var_names=["alpha", "beta", "odds_ratio", "max_prob_slope"])
```

## 3. The Three Levels of Coefficient Interpretation

In non-linear GLMs, a single coefficient $\beta$ can be interpreted on three distinct mathematical scales:

### 1. Log-Odds Scale ($\beta$)
- **Meaning**: A 1-unit increase in $x$ produces an additive change of $\beta$ in the **log-odds** $\log\left(\frac{p}{1-p}\right)$.
- **Limitation**: Highly abstract; humans do not naturally think in log-odds.

### 2. Odds Ratio Scale ($\text{OR} = e^\beta$)
- **Meaning**: A 1-unit increase in $x$ multiplies the **odds of success** by $e^\beta$.
- **Example**: If $\beta = 1.2$, $\text{OR} = e^{1.2} \approx 3.32$. The odds of success are $3.32\times$ higher for each unit increase in $x$.

### 3. Probability Scale ($\Delta P$ & The Divide-by-4 Rule)
- **Meaning**: Because the logistic sigmoid is an S-curve, the change in probability $\Delta P$ per unit change in $x$ is **not constant**—it depends on the baseline probability!
- **The Divide-by-4 Rule (Gelman & Hill)**: The maximum slope of the logistic curve occurs at $p = 0.5$, where the derivative is $\frac{d p}{d x} = \beta p(1-p) = \frac{\beta}{4}$.
  $$\max \left(\frac{\Delta P}{\Delta x}\right) \approx \frac{\beta}{4}$$
  If $\beta = 1.2$, a 1-unit change in $x$ increases the probability of success by at most $\frac{1.2}{4} = 0.30$ ($30$ percentage points).

## Key Takeaways

- Binary outcomes require a **Bernoulli likelihood** with an **inverse logit link** $\text{logit}^{-1}(\alpha + \beta x)$.
- Always place **scale-aware priors** (e.g. $\operatorname{Normal}(0, 1.5)$) on regression coefficients to prevent extreme probability polarization at $p \approx 0$ or $p \approx 1$.
- Convert abstract log-odds coefficients into **Odds Ratios** $\exp(\beta)$ and **Probability Contrasts** $\beta / 4$ for scientific reporting.
