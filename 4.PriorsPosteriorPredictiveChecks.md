# Session 4: Priors, Posterior Uncertainty and Predictive Checking

## 1. Prior Information, Regularization and Scepticism

A prior distribution in Bayesian inference is not an arbitrary subjective whim, nor is it a mathematical nuisance. It is an explicit, transparent statement of our **background scientific knowledge** and physical constraints before conditioning on new data.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    THE MYTH OF THE "OBJECTIVE" FLAT PRIOR                   │
│ ─────────────────────────────────────────────────────────────────────────── │
│ A completely flat uniform prior Beta(1, 1) across θ ∈ [0, 1] is NOT         │
│ "assumption-free":                                                          │
│ 1. It asserts that θ = 0.001 and θ = 0.500 are equally plausible a priori. │
│ 2. When transformed to the log-odds scale logit(θ) = log(θ / (1-θ)),        │
│    it places immense prior mass in the extreme tails (logit(θ) → ±∞).       │
│ 3. On the observable count scale k ~ Binomial(N, θ), it implies that        │
│    observing 0 successes is just as likely as observing N/2 successes!      │
└─────────────────────────────────────────────────────────────────────────────┘
```

**Weakly informative priors** act as scientific regularizers: they rule out physically impossible values, pull estimates away from noisy sample extremes (shrinkage), and stabilize estimation in small samples without overriding strong empirical evidence.

## 2. Prior Elicitation on the Observable Scale

How should a researcher choose hyperparameters $\alpha$ and $\beta$ for a $\text{Beta}(\alpha, \beta)$ prior?

Rather than guessing abstract mathematical parameters, we calibrate priors using two intuitive domain quantities:
1. **The Prior Expected Value ($\mu_0$)**: What is our best baseline expectation for the proportion?
   $$\mu_0 = \frac{\alpha}{\alpha + \beta}$$
2. **The Effective Prior Sample Size ($n_0$)**: How much certainty do we possess, expressed as an equivalent number of prior observations?
   $$n_0 = \alpha + \beta$$

$$\alpha = n_0 \times \mu_0, \quad \beta = n_0 \times (1 - \mu_0)$$

* **Example**: For public policy support expected to be around $60\%$ ($\mu_0 = 0.60$) with the certainty equivalent to having asked 10 previous citizens ($n_0 = 10$), we set:
  $$\alpha = 10 \times 0.60 = 6, \quad \beta = 10 \times (1 - 0.60) = 4 \implies \theta \sim \text{Beta}(6, 4)$$

## 3. The Beta–Binomial Analytic Conjugate Model

When the prior and posterior belong to the same probability family, the prior is said to be **conjugate** to the likelihood. The Beta distribution is the natural conjugate prior for Binomial likelihoods.

### Mathematical Derivation:
* **Prior**: $p(\theta) = \frac{1}{\text{B}(\alpha, \beta)} \theta^{\alpha - 1} (1 - \theta)^{\beta - 1}$
* **Likelihood**: $\mathcal{L}(\theta \mid k, N) = \binom{N}{k} \theta^k (1 - \theta)^{N - k}$
* **Posterior Kernel**:
  $$p(\theta \mid k, N) \propto p(k \mid \theta) p(\theta) \propto \left[ \theta^k (1 - \theta)^{N - k} \right] \times \left[ \theta^{\alpha - 1} (1 - \theta)^{\beta - 1} \right] = \theta^{(\alpha + k) - 1} (1 - \theta)^{(\beta + N - k) - 1}$$

$$\theta \mid k, N \sim \text{Beta}(\alpha + k, \; \beta + N - k)$$

$$\alpha_{\text{post}} = \alpha + k, \quad \beta_{\text{post}} = \beta + N - k$$

### The Posterior Mean as a Precision-Weighted Compromise:
$$\mathbb{E}[\theta \mid k] = \frac{\alpha + k}{\alpha + \beta + N} = \underbrace{\left( \frac{\alpha + \beta}{\alpha + \beta + N} \right)}_{w_{\text{prior}}} \mu_{\text{prior}} + \underbrace{\left( \frac{N}{\alpha + \beta + N} \right)}_{w_{\text{data}}} \hat{\theta}_{\text{MLE}}$$

* When sample size is small ($N \ll n_0$), the posterior is anchored to the prior.
* When sample size is large ($N \gg n_0$), $w_{\text{data}} \to 1$, and the posterior converges to the Maximum Likelihood Estimate $\hat{\theta}_{\text{MLE}} = \frac{k}{N}$.

## 4. Posterior Uncertainty: Equal-Tailed (ETI) vs. Highest Density Intervals (HDI)

To summarize posterior parameter uncertainty, we report a $95\%$ credible interval $[L, U]$ such that $\mathbb{P}(L \le \theta \le U \mid y) = 0.95$:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          ETI versus HDI DEMARCATION                         │
├──────────────────────────────────────┬──────────────────────────────────────┤
│ Equal-Tailed Interval (ETI)          │ Highest Density Interval (HDI)       │
├──────────────────────────────────────┼──────────────────────────────────────┤
│ Places exactly 2.5% probability in   │ The shortest possible interval       │
│ the left tail and 2.5% in the right. │ containing 95% of total mass.        │
├──────────────────────────────────────┼──────────────────────────────────────┤
│ Computed directly via inverse CDF    │ Computed via numerical minimization  │
│ (quantiles 0.025 and 0.975).         │ of interval span L to U.             │
├──────────────────────────────────────┼──────────────────────────────────────┤
│ Invariant under monotonic transforms │ Every point inside the HDI has       │
│ (e.g. log-odds logit(θ)).            │ higher density than outside.         │
├──────────────────────────────────────┼──────────────────────────────────────┤
│ Matches HDI on symmetric posteriors; │ Strictly encompasses the mode on     │
│ can include low-density tail values. │ highly skewed or bounded posteriors. │
└──────────────────────────────────────┴──────────────────────────────────────┘
```

## 5. Posterior Predictive Checking: Forecasting Future Counts

The **posterior predictive distribution** $p(\tilde{y} \mid y)$ integrates over our remaining parameter uncertainty to forecast future observations $\tilde{y}$ in a new replication of size $\tilde{N}$:

$$p(\tilde{y} \mid k, N, \tilde{N}) = \int_0^1 \text{Binomial}(\tilde{y} \mid \tilde{N}, \theta) \text{Beta}(\theta \mid \alpha_{\text{post}}, \beta_{\text{post}}) d\theta = \binom{\tilde{N}}{\tilde{y}} \frac{\text{B}(\alpha_{\text{post}} + \tilde{y}, \; \beta_{\text{post}} + \tilde{N} - \tilde{y})}{\text{B}(\alpha_{\text{post}}, \beta_{\text{post}})}$$

* **Predictive Mean**: $\mathbb{E}[\tilde{y} \mid k] = \tilde{N} \times \frac{\alpha_{\text{post}}}{\alpha_{\text{post}} + \beta_{\text{post}}}$.
* **Predictive Variance Inflation**:
  $$\text{Var}(\tilde{y} \mid k) = \tilde{N} \mu_{\text{post}} (1 - \mu_{\text{post}}) \left[ 1 + \frac{\tilde{N} - 1}{\alpha_{\text{post}} + \beta_{\text{post}} + 1} \right]$$
  * Notice that the predictive variance is strictly larger than simple binomial variance $\tilde{N}\mu(1-\mu)$, because it explicitly incorporates our epistemic parameter uncertainty!

## 6. Sensitivity Analysis: The Sex-Ratio Case Study (*ROS* Chapter 9)

In a study of $N = 100$ consecutive births, a hospital records $k = 60$ boys and $40$ girls. A naive frequentist analysis claims that the sex ratio at birth is $\hat{\theta} = 60\%$ ($p = 0.045$).

### Why Background Knowledge Matters:
Centuries of demographic data establish that the human proportion of male births is biologically stable around $\theta \approx 0.488$ with extreme stability.

| Prior Specification | Prior Hyperparameters | Observed Data | Posterior Distribution | Posterior Mean | 95% Credible Interval |
|:---|:---:|:---:|:---:|:---:|:---:|
| **1. Flat / Uniform** | $\text{Beta}(1, 1)$ | $k=60, N=100$ | $\text{Beta}(61, 41)$ | **0.598** | $[0.501, 0.690]$ |
| **2. Weakly Informative** | $\text{Beta}(5, 5)$ | $k=60, N=100$ | $\text{Beta}(65, 45)$ | **0.591** | $[0.497, 0.681]$ |
| **3. Skeptical Prior** | $\text{Beta}(25, 25)$ | $k=60, N=100$ | $\text{Beta}(85, 65)$ | **0.567** | $[0.486, 0.645]$ |
| **4. Historical Demographic** | $\text{Beta}(488, 512)$ | $k=60, N=100$ | $\text{Beta}(548, 552)$ | **0.498** | $[0.468, 0.528]$ |

:::{important}
Under the historical biological prior ($n_0 = 1,000$ births), the spurious $60\%$ fluctuation in a small sample of $100$ is appropriately shrunk back to **$49.8\%$** ($95\%$ CI $[46.8\%, 52.8\%]$). The prior prevents false-positive scientific discoveries!
:::

## 8. Concept Check

````{dropdown} ❓ Why does a large prior effective sample size n_0 reduce sensitivity to new data?
Because the posterior mean is a weighted average $w_{\text{prior}} \mu_{\text{prior}} + (1 - w_{\text{prior}}) \hat{\theta}_{\text{MLE}}$ where $w_{\text{prior}} = \frac{n_0}{n_0 + N}$. If $n_0 = 1{,}000$ and $N = 20$, the prior receives over $98\%$ of the total weighting.
````

````{dropdown} ❓ Does an Equal-Tailed Interval (ETI) always contain the posterior mode?
**No.** For highly skewed distributions (e.g. near boundary 0 or 1), the ETI can exclude the mode while including long tail regions with near-zero probability density. In such cases, the **Highest Density Interval (HDI)** is preferred.
````

````{dropdown} ❓ What is prior-data conflict?
Prior-data conflict occurs when the observed data concentrates in a region where the prior assigned near-zero probability. It signals that either the prior was overly dogmatic or the data-generating process contains unexpected anomalies.
````
