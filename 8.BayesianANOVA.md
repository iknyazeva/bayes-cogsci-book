# Bayesian ANOVA and Factorial Designs

## 1. Beyond Classical ANOVA: A Model-Based Approach

In classical experimental psychology, Analysis of Variance (ANOVA) is traditionally taught as a collection of $F$-tests derived from partitioning sums of squares ($\text{SS}_{\text{total}} = \text{SS}_{\text{between}} + \text{SS}_{\text{within}}$).

In the Bayesian framework, ANOVA is not a special set of tests—it is simply a **linear regression model with categorical predictors** and structured prior distributions.

### Advantages of Bayesian ANOVA:
1. **Unbalanced Designs**: In factorial experiments where cell counts are unequal ($n_{jk} \neq n$), classical Type I/II/III sum-of-squares methods yield conflicting $F$-statistics. Bayesian estimation seamlessly handles unbalanced cells via the exact joint posterior.
2. **Heterogeneous Variance**: Classical ANOVA assumes equal variance across all factor cells. Bayesian models can assign cell-specific standard deviations $\sigma_{jk}$.
3. **Hierarchical Shrinkage**: When cells have small sample sizes, hierarchical cell-means priors prevent extreme cell estimates from dominating the analysis.

## 2. Factorial Parameterizations: Contrast Coding vs. Cell-Means

Consider a $2 \times 3$ factorial design with two factors: Factor $A$ (2 levels) and Factor $B$ (3 levels), yielding $J = 6$ distinct experimental conditions (cells).

### 1. The Classical Contrast / Dummy Parameterization
$$
y_i = \mu_0 + \alpha_{\text{wool}} + \beta_{\text{tension}} + (\alpha\beta)_{\text{wool} \times \text{tension}} + \epsilon_i
$$
To identify this model, classical software enforces sum-to-zero constraints ($\sum \alpha = 0$) or sets a reference baseline (dummy coding). However, this creates complex posterior correlations between main effects and interaction terms.

### 2. The Cell-Means Parameterization (Recommended)
Instead of decomposing variance into arbitrary main-effect contrasts, we estimate the **direct mean for each cell** $\mu_j$ ($j = 1, \dots, 6$):

$$
y_i \sim \operatorname{Normal}(\mu_{\text{cell}[i]}, \sigma), \quad \mu_{\text{cell}} \sim \operatorname{Normal}(\mu_0, \tau_{\text{cell}})
$$

Substantive scientific contrasts (e.g., main effect of tension, interaction effects) are computed effortlessly as **derived deterministic differences** from posterior samples.

## 3. Empirical Case Study: Loom Yarn Breaks (`warpbreaks`)

We examine the classic industrial dataset `warpbreaks` ($N = 54$), measuring the number of yarn breaks per loom ($y$, modeled as $\log(\text{breaks})$) across two types of wool ($\text{Wool } A, B$) and three levels of loom tension ($\text{Low, Medium, High}$).

### Model Specification in PyMC

```python
import pymc as pm
import pandas as pd
import numpy as np
import arviz as az

# Encode cell indices (0 to 5)
df["cell_idx"] = pd.factorize(df["wool"] + "_" + df["tension"], sort=True)[0]
n_cells = 6

with pm.Model() as hierarchical_anova:
    # Grand mean and cell variance
    mu0 = pm.Normal("mu0", mu=df["log_breaks"].mean(), sigma=1.0)
    tau_cell = pm.HalfNormal("tau_cell", sigma=0.5)
    sigma_y = pm.HalfNormal("sigma_y", sigma=0.5)
    
    # Non-centered cell effects
    z_cell = pm.Normal("z_cell", mu=0.0, sigma=1.0, shape=n_cells)
    mu_cell = pm.Deterministic("mu_cell", mu0 + tau_cell * z_cell)
    
    # Likelihood
    y_obs = pm.Normal("y_obs", mu=mu_cell[df["cell_idx"]], sigma=sigma_y, observed=df["log_breaks"])
    
    # Custom Substantive Contrasts:
    # Contrast 1: Tension effect in Wool A (Low vs High)
    tension_eff_A = pm.Deterministic("tension_eff_A", mu_cell[0] - mu_cell[2])
    # Contrast 2: Wool difference at Low tension
    wool_diff_low = pm.Deterministic("wool_diff_low", mu_cell[0] - mu_cell[3])
    
    idata_anova = pm.sample(draws=2000, tune=1000, target_accept=0.95)
```

## 4. Model Comparison: Additive vs. Interaction Models via LOO-CV

To determine whether an interaction term is justified, we compare the **Additive Model** (independent wool and tension effects) against the **Interaction Model** using Pareto-smoothed Importance Sampling Leave-One-Out Cross-Validation (**PSIS-LOO**):

```python
# Compare candidate ANOVA models
cmp = az.compare({
```

## Key Takeaways

- Bayesian ANOVA reformulates classical $F$-tests as **cell-means regression models** with hierarchical shrinkage.
- Post-hoc pairwise comparisons and complex contrasts are computed directly from the posterior draws without requiring multiplicity $p$-value corrections (e.g. Bonferroni/Tukey) because **hierarchical shrinkage automatically controls false positives**.
- Use **LOO-CV** to evaluate whether interaction terms provide genuine out-of-sample predictive improvement.
