# Bayesian Hypothesis Testing & The Savage–Dickey Bayes Factor

## 1. Estimation vs. Hypothesis Testing

In Bayesian data analysis, researchers frequently face two distinct statistical questions:
1. **Estimation (Parameter Uncertainty)**: *"What is the plausible magnitude of the effect $\delta$, and what is our 95% Credible Interval?"* (Answered via posterior distributions, HDIs, and ROPE).
2. **Hypothesis Testing (Model Comparison)**: *"How much more likely are the observed data under an effect model ($H_1: \delta \neq 0$) compared to a strict invariance model ($H_0: \delta = 0$)?"* (Answered via **Bayes Factors**).

When evaluating nested point null hypotheses in cognitive psychology (e.g., Stroop effect, memory priming, pledge intervention effects), the **Savage–Dickey Density Ratio** provides an elegant, exact computational shortcut to compute Bayes Factors without estimating high-dimensional marginal likelihood integrals.

---

## 2. The Savage–Dickey Density Ratio Method

Suppose we compare two models:
- **Null Model $H_0$**: $\delta = \delta_0 = 0$ (a single point hypothesis).
- **Alternative Model $H_1$**: $\delta \sim p(\delta \mid H_1)$ (an unconstrained prior over the effect size).

Dickey (1971) proved that under nested parameterizations, the **Bayes Factor in favor of the null ($\text{BF}_{01}$)** equals the ratio of the **posterior density height at $\delta = 0$** to the **prior density height at $\delta = 0$**:

$$
\text{BF}_{01} = \frac{p(y \mid H_0)}{p(y \mid H_1)} = \frac{p(\delta = 0 \mid y, H_1)}{p(\delta = 0 \mid H_1)}
$$

Correspondingly, the Bayes Factor in favor of the alternative is:

$$
\text{BF}_{10} = \frac{1}{\text{BF}_{01}} = \frac{p(\delta = 0 \mid H_1)}{p(\delta = 0 \mid y, H_1)}
$$

### Interpreting Bayes Factor Values (Jeffreys' Evidence Scale)

| $\text{BF}_{10}$ | Strength of Evidence for $H_1$ over $H_0$ |
|---|---|
| $> 100$ | Decisive / Extreme evidence for $H_1$ |
| $30 - 100$ | Very Strong evidence for $H_1$ |
| $10 - 30$ | Strong evidence for $H_1$ |
| $3 - 10$ | Moderate evidence for $H_1$ |
| $1 - 3$ | Anecdotal / Inconclusive evidence |
| $1$ | No evidence (data equally likely under both) |
| $< 1/3$ | Moderate evidence for $H_0$ (Invariance) |

## 3. Empirical Case Study: The Pledger Experiment

In a study by Wagenmakers et al. (2010), researchers investigated whether getting people to sign an ethical pledge reduced dishonest behavior. 
- **Pledgers**: $s_1 = 424$ successes out of $n_1 = 777$ trials ($\hat{\theta}_1 \approx 54.6\%$).
- **Non-Pledgers**: $s_2 = 5416$ successes out of $n_2 = 9072$ trials ($\hat{\theta}_2 \approx 59.7\%$).

We test whether the rate difference $\delta = \theta_1 - \theta_2$ is strictly zero ($H_0: \delta = 0$) or non-zero ($H_1: \delta \neq 0$):

```python
import pymc as pm
import numpy as np
import arviz as az
from scipy.stats import gaussian_kde

with pm.Model() as pledge_model:
    # Priors under H1
    theta1 = pm.Beta("theta1", alpha=1.0, beta=1.0)
    theta2 = pm.Beta("theta2", alpha=1.0, beta=1.0)
    
    # Effect size delta
    delta = pm.Deterministic("delta", theta1 - theta2)
    
    # Binomial Likelihoods
    pm.Binomial("s1_obs", n=777, p=theta1, observed=424)
    pm.Binomial("s2_obs", n=9072, p=theta2, observed=5416)
    
    idata = pm.sample(draws=4000, tune=2000, target_accept=0.95)

# Compute Savage-Dickey density ratio
post_delta = idata.posterior["delta"].values.ravel()
prior_delta = np.random.beta(1, 1, 30000) - np.random.beta(1, 1, 30000)

kde_post = gaussian_kde(post_delta)
kde_prior = gaussian_kde(prior_delta)

post_at_0 = float(kde_post(0.0))
prior_at_0 = float(kde_prior(0.0))

bf01 = post_at_0 / prior_at_0
bf10 = 1.0 / bf01
print(f"BF01 = {bf01:.2f} | BF10 = {bf10:.2f}")
```

**Result:** $\text{BF}_{01} \approx 0.45 \implies \text{BF}_{10} \approx 2.22$. The data provide only anecdotal/weak evidence in favor of the pledge effect.

## 4. Order-Restricted Hypotheses (Directional Testing)

Often, scientific theories predict a specific direction (e.g., $H_-: \delta < 0$, pledging strictly *decreases* dishonesty). 

The directional Bayes Factor is computed by multiplying the unrestricted Savage-Dickey ratio by the ratio of directional probabilities:

$$
\text{BF}_{0 -} = \text{BF}_{01} \times \frac{P(\delta < 0 \mid H_1)}{P(\delta < 0 \mid y, H_1)}
$$

Because $98.5\%$ of the posterior mass is negative while only $50\%$ of the prior mass is negative:
$$
\text{BF}_{- 0} = \frac{1}{\text{BF}_{0-}} = 2.22 \times \frac{0.985}{0.50} \approx 4.37 \quad (\text{Moderate Evidence})
$$

## 5. The Jeffreys–Lindley Paradox & Prior Sensitivity Warning

```{warning}
**Bayes Factors are Inherently Sensitive to Prior Width:**
Unlike parameter estimation (where 95% HDIs are robust to wide priors when sample size is large), **Bayes Factors directly depend on the scale of the prior $p(\delta \mid H_1)$**.

If you specify an excessively diffuse prior (e.g., $\delta \sim \operatorname{Normal}(0, 1000)$), the prior density at zero $p(\delta = 0 \mid H_1)$ drops to near zero ($0.0004$). Consequently, the Savage–Dickey ratio $\text{BF}_{01} = \frac{p(0 \mid y)}{p(0 \mid H_1)}$ **explodes toward infinity**, falsely claiming overwhelming evidence for $H_0$!

**Recommendation:** Always use theoretically grounded, unit-information priors ($\delta \sim \operatorname{Cauchy}(0, 0.707)$ or $\operatorname{Normal}(0, 1)$), and accompany all Bayes Factor claims with a **prior sensitivity plot**.
```

---

## Key Takeaways

- The **Savage–Dickey method** computes the Bayes Factor for a point null by taking the ratio of posterior density to prior density at $\delta = 0$.
- Directional hypotheses ($H_+$ or $H_-$) incorporate the proportion of posterior draws in the predicted direction.
- Bayes Factors test the **relative predictive plausibility** of two models; they require carefully chosen prior scales and sensitivity audits.
