# Count Models: Poisson and Negative-Binomial

## 1. Modeling Discrete Event Counts

Count data arise everywhere in cognitive science, neuroscience, and social science:
- Number of eye fixation saccades on an area of interest.
- Number of recall errors made during a memory retention task.
- Number of behavioral symptoms reported by patients.

Counts are **non-negative integers** ($y_i \in \{0, 1, 2, \dots\}$) with right-skewed distributions and variance that naturally scales with the mean. Standard Gaussian models fail because they predict negative counts and enforce constant additive variance.

---

## 2. Poisson Likelihood, Log-Link & Exposure Offsets

The baseline model for counts is the **Poisson distribution**, parameterized by rate $\lambda > 0$:

$$
y_i \sim \operatorname{Poisson}(\lambda_i), \quad \log(\lambda_i) = \log(u_i) + \alpha + \beta x_i
$$

### The Role of Exposure Offsets ($\log(u_i)$)
If participant $i$ was observed for $u_i$ minutes (or had an area of $u_i$ square meters), the expected count is proportional to exposure: $\mathbb{E}[y_i] = u_i \cdot \text{Rate}_i$. 
Taking the logarithm:
$$
\log(\mathbb{E}[y_i]) = \log(u_i) + \underbrace{\alpha + \beta x_i}_{\text{Rate per unit exposure}}
$$
Here, $\log(u_i)$ enters the linear predictor with a **fixed coefficient of 1.0** (called an **offset**).

---

## 3. Overdispersion and the Negative-Binomial Model

A rigid mathematical property of the Poisson distribution is **equidispersion**:

$$
\operatorname{Mean}(Y) = \operatorname{Var}(Y) = \lambda
$$

In real behavioral data, unobserved heterogeneity, clustering, and bursting cause **overdispersion** ($\operatorname{Var}(Y) > \operatorname{Mean}(Y)$). Fitting a Poisson model to overdispersed counts severely underestimates standard errors, generating false-positive scientific claims.

To accommodate extra-Poisson variance, we use the **Negative-Binomial distribution**:

$$
y_i \sim \operatorname{NegativeBinomial}(\mu_i, \phi), \quad \operatorname{Var}(y_i) = \mu_i + \frac{\mu_i^2}{\phi}
$$

- $\mu_i = \exp(\log(u_i) + \alpha + \beta x_i)$ is the expected count.
- $\phi > 0$ is the **dispersion parameter**.
- As $\phi \to \infty$, the extra-variance term $\mu^2/\phi \to 0$, recovering the pure Poisson model.

## 4. Forward Data Simulation and PyMC Implementation

We simulate $N = 100$ count observations with exposure variation $u_i \in [1, 5]$ and overdispersion $\phi = 2.0$:

```python
import numpy as np
import pymc as pm
import arviz as az

# 1. Forward Simulation of Overdispersed Counts
np.random.seed(42)
N = 100
x_sim = np.random.uniform(-2, 2, N)
exposure_u = np.random.uniform(1.0, 5.0, N)

alpha_true = 0.8
beta_true = 0.5
phi_true = 2.0

# Expected count mu_i = u_i * exp(alpha + beta * x)
mu_true = exposure_u * np.exp(alpha_true + beta_true * x_sim)
p_nb = phi_true / (phi_true + mu_true)
y_sim = np.random.negative_binomial(n=phi_true, p=p_nb)

# 2. Negative-Binomial Model in PyMC
with pm.Model() as negbin_model:
    # Priors
    alpha = pm.Normal("alpha", mu=0.0, sigma=2.0)
    beta = pm.Normal("beta", mu=0.0, sigma=1.0)
    phi = pm.Exponential("phi", lam=0.5)
    
    # Linear predictor with exposure offset
    log_mu = np.log(exposure_u) + alpha + beta * x_sim
    mu = pm.Deterministic("mu", pm.math.exp(log_mu))
    
    # Multiplicative Rate Multiplier
    rate_multiplier = pm.Deterministic("rate_multiplier", pm.math.exp(beta))
    
    # Likelihood
    y_obs = pm.NegativeBinomial("y_obs", mu=mu, alpha=phi, observed=y_sim)
    
    idata_count = pm.sample(draws=2000, tune=1000, target_accept=0.95)

az.summary(idata_count, var_names=["alpha", "beta", "phi", "rate_multiplier"])
```

## 5. Multiplicative Interpretation of Count Coefficients

Because of the logarithmic link function ($\log \mu = \alpha + \beta x$), coefficients are **multiplicative rate multipliers**:

$$
\mu(x + 1) = \mu(x) \cdot e^\beta
$$

- If $\beta = 0.5$, the rate multiplier is $e^{0.5} \approx 1.65$. Each 1-unit increase in $x$ multiplies the expected event rate by **$1.65$** (a **$+65\%$ increase**).
- If $\beta = -0.3$, the rate multiplier is $e^{-0.3} \approx 0.74$ (a **$26\%$ reduction** in event rate).

---

## Key Takeaways

- Discrete counts require a **Poisson** or **Negative-Binomial** likelihood with a **log link**.
- Always use **offsets $\log(u_i)$** when observations differ in observation time, trial counts, or spatial area.
- Check for **overdispersion** ($\operatorname{Var} > \text{Mean}$); when present, use the Negative-Binomial model with dispersion parameter $\phi$ to avoid false-positive discoveries.
