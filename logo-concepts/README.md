# Logo concepts

Four icon-only directions for *Bayesian Analysis of Empirical Data*:

1. `01-data-to-posterior.svg` — observations becoming a posterior distribution.
2. `02-updating-curves.svg` — prior and likelihood converging into a posterior.
3. `03-bayesian-lens.svg` — empirical observations viewed through a Bayesian lens.
4. `04-distribution-b.svg` — an abstract B monogram made from density curves.

All four use a transparent background and a shared blue–green palette. They are exploratory SVGs and do not replace `logo.png`.
