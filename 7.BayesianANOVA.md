# Categorical Predictors and Factorial Contrasts

## 1. ANOVA as Regression: A Unified Model-Based Approach

In classical experimental psychology and empirical research, Analysis of Variance (ANOVA) is often taught as a rigid taxonomy of $F$-tests based on partitioning sums of squares ($\text{SS}_{\text{total}} = \text{SS}_{\text{between}} + \text{SS}_{\text{within}}$).

In modern Bayesian data analysis, ANOVA is not a distinct inferential philosophy—it is simply a **linear regression model with categorical predictors, indicator/cell-means coding, and planned contrasts**.

### Why Bayesian ANOVA Outperforms Classical ANOVA:
1. **Unequal Variances (Heteroskedasticity)**: Classical ANOVA strictly assumes all groups share the exact same variance $\sigma^2$. If groups have different spreads ($\sigma_1 \neq \sigma_2 \neq \sigma_3$), classical $F$-tests inflate Type I error. Bayesian ANOVA estimates group-specific standard deviations $\sigma_j$ naturally.
2. **Unbalanced Factorial Cells ($n_{jk} \neq n$)**: When sample sizes vary across experimental conditions, classical Type I/II/III sums of squares give contradictory results. Bayesian estimation computes the exact joint posterior regardless of sample balance.
3. **No Multiplicity Penalties for Pairwise Contrasts**: Classical post-hoc testing requires conservative $p$-value corrections (Bonferroni, Tukey HSD). In Bayesian ANOVA, **hierarchical shrinkage automatically pulls noisy extreme group estimates toward the grand mean**, naturally controlling false discoveries without discarding statistical power.

## 2. One-Way ANOVA: Comparing Multiple Groups ($K \ge 3$)

Suppose we measure a continuous outcome across $K = 4$ independent experimental conditions (e.g., control, drug low, drug high, behavioral therapy).

$$
y_{ij} \sim \operatorname{Normal}(\mu_j, \sigma_j), \quad j = 1, \dots, K
$$

```python
import pymc as pm
import numpy as np
import arviz as az

with pm.Model() as oneway_anova:
    # Scale-calibrated priors for group means and group scales
    mu_pool = df["value"].mean()
    sd_pool = df["value"].std() * 2.0
    
    mu = pm.Normal("mu", mu=mu_pool, sigma=sd_pool, shape=n_groups)
    sigma = pm.HalfNormal("sigma", sigma=sd_pool, shape=n_groups)
    
    # Likelihood with group indexing
    y_obs = pm.Normal("y_obs", mu=mu[df["group_id"]], sigma=sigma[df["group_id"]], observed=df["value"])
    
    # All Pairwise Contrasts computed simultaneously:
    diff_1_2 = pm.Deterministic("diff_1_2", mu[0] - mu[1])
    diff_1_3 = pm.Deterministic("diff_1_3", mu[0] - mu[2])
    diff_2_4 = pm.Deterministic("diff_2_4", mu[1] - mu[3])
    
    idata_oneway = pm.sample(draws=2000, tune=1000)
```

## 3. Two-Way Factorial ANOVA: Contrast Coding vs. Cell-Means

In a factorial experiment with two factors (e.g., Factor A with 2 levels, Factor B with 3 levels), we have $J = 6$ distinct experimental conditions (cells).

### The Classical Dummy Contrast Dilemma
$$
y_i = \mu_0 + \alpha_{\text{wool}} + \beta_{\text{tension}} + (\alpha\beta)_{\text{wool} \times \text{tension}} + \epsilon_i
$$
Classical software enforces arbitrary sum-to-zero constraints ($\sum \alpha = 0$) or corner-point dummy coding, creating complex posterior correlations between main effects and interaction coefficients.

### The Cell-Means Parameterization (Recommended)
Instead of decomposing variance into arbitrary contrast tables, we estimate the **direct mean for each cell** $\mu_j$ ($j = 1, \dots, 6$):

$$
y_i \sim \operatorname{Normal}(\mu_{\text{cell}[i]}, \sigma_y), \quad \mu_{\text{cell}} \sim \operatorname{Normal}(\mu_0, \tau_{\text{cell}})
$$

Substantive scientific contrasts (e.g., main effect of tension, interaction effects) are computed directly from posterior samples.

## 4. Empirical Case Study: Loom Yarn Breaks (`warpbreaks`)

We analyze the classic dataset `warpbreaks` ($N = 54$), measuring the number of yarn breaks per loom ($y$, modeled on the log scale $\log(\text{breaks})$) across two types of wool ($\text{Wool } A, B$) and three levels of loom tension ($\text{Low, Medium, High}$).

```python
import pandas as pd
import statsmodels.api as sm

# Load warpbreaks data
df = sm.datasets.get_rdataset("warpbreaks", "datasets").data
df["log_breaks"] = np.log(df["breaks"])
df["cell_idx"] = pd.factorize(df["wool"] + "_" + df["tension"], sort=True)[0]
n_cells = 6

with pm.Model() as hierarchical_cell_means:
    # Hyperpriors for grand mean and between-cell variance
    mu0 = pm.Normal("mu0", mu=df["log_breaks"].mean(), sigma=1.0)
    tau_cell = pm.HalfNormal("tau_cell", sigma=0.5)
    sigma_y = pm.HalfNormal("sigma_y", sigma=0.5)
    
    # Non-centered cell effects
    z_cell = pm.Normal("z_cell", mu=0.0, sigma=1.0, shape=n_cells)
    mu_cell = pm.Deterministic("mu_cell", mu0 + tau_cell * z_cell)
    
    # Likelihood
    y_obs = pm.Normal("y_obs", mu=mu_cell[df["cell_idx"]], sigma=sigma_y, observed=df["log_breaks"])
    
    # Key Substantive Contrasts:
    # 1. Tension effect in Wool A (Low vs High)
    tension_eff_A = pm.Deterministic("tension_eff_A", mu_cell[0] - mu_cell[2])
    # 2. Wool difference at Low tension
    wool_diff_low = pm.Deterministic("wool_diff_low", mu_cell[0] - mu_cell[3])
    
    idata_hier = pm.sample(draws=2000, tune=1000, target_accept=0.95)
```

## Key Takeaways

- Bayesian ANOVA replaces classical sum-of-squares partitioning with **cell-means regression models** and hierarchical shrinkage.
- Multi-group comparisons estimate **group-specific variances** ($\sigma_j \neq \sigma_k$) without requiring homoskedasticity assumptions.
- Hierarchical cell-means shrinkage pulls noisy cell estimates toward the grand mean, **controlling false discovery rates automatically** without ad-hoc Bonferroni corrections.
- Model selection between additive and interaction structures is performed via **PSIS-LOO out-of-sample predictive accuracy**.
