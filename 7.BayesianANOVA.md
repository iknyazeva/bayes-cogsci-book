# Categorical Predictors and Factorial Contrasts

## 1. ANOVA as Regression: A Unified Model-Based Approach

In classical psychology and empirical science, Analysis of Variance (ANOVA) is often taught as a rigid taxonomy of $F$-tests based on partitioning sums of squares:

$$
\text{SS}_{\text{total}} = \text{SS}_{\text{between}} + \text{SS}_{\text{within}}
$$

In modern Bayesian data analysis, ANOVA is not a separate branch of statistics. It is simply a **linear regression model with categorical predictors, indicator/cell-means coding, and planned contrasts**.

### Why Bayesian ANOVA Outperforms Classical ANOVA:
1. **Unequal Variances (Heteroskedasticity)**: Classical ANOVA strictly assumes all groups share the exact same variance $\sigma^2$. If groups differ in variability ($\sigma_1 \neq \sigma_2 \neq \sigma_3$), classical $F$-tests inflate Type I error. In Bayesian regression, we can estimate group-specific standard deviations $\sigma_j$ naturally.
2. **Unbalanced Factorial Cells ($n_{jk} \neq n$)**: When sample sizes vary across experimental conditions, classical Type I, II, and III sums of squares produce contradictory results. Bayesian estimation computes the exact joint posterior regardless of cell balance.
3. **Contrasts Without Multiplicity Penalties**: Classical post-hoc testing requires conservative $p$-value corrections (Bonferroni, Tukey HSD) that discard statistical power. In the Bayesian framework, we compute exact posterior distributions for any planned contrast directly from posterior draws.

## 2. One-Way ANOVA: Comparing Multiple Groups ($K \ge 3$)

Suppose an experiment measures cognitive performance across $K = 4$ independent treatment conditions (e.g., Control, Low Dose, High Dose, Behavioral Therapy):

$$
y_{ij} \sim \operatorname{Normal}(\mu_j, \sigma), \quad j = 1, \dots, K
$$

Rather than testing whether "at least one group differs from the rest" with a blanket $F$-test, we estimate the location of each group $\mu_j$ directly:

```python
import pymc as pm
import numpy as np
import arviz as az

with pm.Model() as oneway_anova:
    # Scale-calibrated priors for group means
    mu_pool = df["value"].mean()
    sd_pool = df["value"].std() * 2.0
    
    # Independent vector of group means
    mu = pm.Normal("mu", mu=mu_pool, sigma=sd_pool, shape=n_groups)
    sigma = pm.HalfNormal("sigma", sigma=sd_pool)
    
    # Likelihood with group indexing
    y_obs = pm.Normal("y_obs", mu=mu[df["group_id"]], sigma=sigma, observed=df["value"])
    
    # Planned Substantive Contrasts (computed simultaneously):
    diff_low_ctrl = pm.Deterministic("diff_low_ctrl", mu[1] - mu[0])
    diff_high_ctrl = pm.Deterministic("diff_high_ctrl", mu[2] - mu[0])
    diff_high_low = pm.Deterministic("diff_high_low", mu[2] - mu[1])
    
    idata_oneway = pm.sample(draws=2000, tune=1000)
```

Every pairwise comparison has a full posterior distribution, credible interval, and probability of exceeding zero on the original measurement scale.

## 3. Two-Way Factorial Designs: Cell-Means vs. Dummy Coding

In a factorial experiment with two factors (e.g., Factor A with 2 levels, Factor B with 3 levels), we have $2 \times 3 = 6$ distinct experimental conditions (cells).

### The Classical Dummy Contrast Dilemma
Classical regression decomposes the outcome as:

$$
y_i = \mu_0 + \alpha_{\text{FactorA}} + \beta_{\text{FactorB}} + (\alpha\beta)_{\text{A} \times \text{B}} + \epsilon_i
$$

Software enforces arbitrary sum-to-zero constraints ($\sum \alpha = 0$) or reference corner-point dummy coding, creating complex posterior correlations between main effect coefficients and interaction terms.

### The Cell-Means Parameterization (Recommended)
Instead of decomposing variance into arbitrary contrast tables, we directly estimate the **mean for each cell** $\mu_{j}$ ($j = 1, \dots, 6$):

$$
y_i \sim \operatorname{Normal}(\mu_{\text{cell}[i]}, \sigma)
$$

```python
# Create a unique cell index for each combination of factors
df["cell_idx"] = pd.factorize(df["factor_a"].astype(str) + "_" + df["factor_b"].astype(str))[0]
n_cells = 6

with pm.Model() as cell_means_model:
    mu_cells = pm.Normal("mu_cells", mu=df["value"].mean(), sigma=df["value"].std() * 2, shape=n_cells)
    sigma = pm.HalfNormal("sigma", sigma=df["value"].std())
    
    y_obs = pm.Normal("y_obs", mu=mu_cells[df["cell_idx"]], sigma=sigma, observed=df["value"])
    
    # Main effects and interactions are simple linear contrasts of cell means:
    # e.g., Effect of Factor B level 2 vs level 1 within Factor A level 1:
    contrast_simple = pm.Deterministic("contrast_simple", mu_cells[1] - mu_cells[0])
    
    idata_cells = pm.sample(draws=2000, tune=1000)
```

## Key Takeaways

- Classical ANOVA is simply a **linear regression model with categorical predictors**.
- The **cell-means parameterization** avoids confusing dummy-coding reference traps and allows arbitrary planned contrasts to be calculated directly from posterior draws.
- In Bayesian regression, unequal variances across groups ($\sigma_j \neq \sigma_k$) are handled naturally.
- Multiplicity corrections (like Bonferroni) are unnecessary when reporting posterior distributions for planned contrasts.
