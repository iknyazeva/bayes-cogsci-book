# Generalized Linear Models (GLMs)

## 1. The Generalized Linear Model Architecture

When outcomes are binary (yes/no), counts (number of errors, fixations, or neural spikes), or ordered categories (Likert rating scales), the standard Gaussian regression model fails:
1. Predictions can produce **impossible values** (e.g., negative counts, probabilities outside $[0, 1]$).
2. The assumption of **constant variance** ($\sigma^2$) is violated because variance naturally depends on the mean (e.g., in a Bernoulli trial, $\operatorname{Var}(Y) = p(1-p)$; in a Poisson process, $\operatorname{Var}(Y) = \mu$).

The **Generalized Linear Model (GLM)** solves this by decomposing the regression into three components:
1. **Random Component (Likelihood)**: An exponential-family distribution $p(y_i \mid \theta_i)$ (e.g., Bernoulli, Binomial, Poisson, Negative-Binomial).
2. **Systematic Component (Linear Predictor)**: $\eta_i = \alpha + \beta_1 x_{i1} + \dots + \beta_k x_{ik} = X_i \beta$.
3. **Link Function $g(\cdot)$**: A monotonic function mapping the expected outcome $\mu_i = \mathbb{E}[y_i]$ to the unbounded real line $\eta_i \in (-\infty, \infty)$:
   $$
   g(\mu_i) = \eta_i \iff \mu_i = g^{-1}(\eta_i)
   $$

| Outcome Type | Likelihood $p(y \mid \theta)$ | Support | Canonical Link $g(\mu)$ | Inverse Link $g^{-1}(\eta)$ |
|---|---|---|---|---|
| Continuous / Symmetric | $\operatorname{Normal}(\mu, \sigma)$ | $\mathbb{R}$ | Identity: $\mu$ | $\eta$ |
| Binary / Proportion | $\operatorname{Bernoulli}(p)$ / $\operatorname{Binomial}(n, p)$ | $\{0, 1\}$ / $\{0, \dots, n\}$ | Logit: $\log\left(\frac{p}{1-p}\right)$ | Logistic: $\frac{1}{1 + e^{-\eta}}$ |
| Non-negative Counts | $\operatorname{Poisson}(\lambda)$ / $\operatorname{NegBinomial}(\mu, \alpha)$ | $\{0, 1, 2, \dots\}$ | Log: $\log(\mu)$ | Exponential: $e^\eta$ |
| Ordered Ratings | $\operatorname{OrderedLogistic}(c, \eta)$ | $\{1, 2, \dots, K\}$ | Ordered Logit | Cutpoint Probabilities |

## 2. Binary Outcomes & Logistic Regression

For binary decisions $y_i \in \{0, 1\}$, we model:

$$
y_i \sim \operatorname{Bernoulli}(p_i), \quad \operatorname{logit}(p_i) = \log\left( \frac{p_i}{1 - p_i} \right) = \alpha + \beta x_i
$$

$$
p_i = \operatorname{logit}^{-1}(\alpha + \beta x_i) = \frac{1}{1 + \exp(-(\alpha + \beta x_i))}
$$

### Interpreting on the Observable Probability Scale ($\Delta P$)
A regression coefficient $\beta$ in logistic regression is on the **log-odds scale**, which is unintuitive for non-statisticians. To communicate substantive results, compute **average predictive comparisons ($\Delta P$)** or the **Divide-by-4 Rule**:
- The maximum slope of the logistic sigmoid occurs at $p = 0.5$, where $\frac{\partial p}{\partial x} = \frac{\beta}{4}$.
- Thus, a 1-unit increase in $x$ changes the probability by at most $\beta / 4$ (e.g., $\beta = 0.8 \implies \Delta P \le +20\%$).

## 3. Complete Separation and Bayesian Regularization

In small samples or extreme configurations, a predictor may perfectly divide successes from failures (e.g., all patients with dosage $> 50$ survive).
- **Maximum Likelihood Estimate (MLE)**: Fails completely ($\hat{\beta}_{\text{MLE}} \to \infty$, standard errors explode to $\pm 1000$).
- **Bayesian Solution**: Proper, weakly informative Gaussian or Student-$t$ priors ($\beta \sim \operatorname{Normal}(0, 2.5)$) act as a natural regularizer, bounding the posterior within realistic odds-ratio ranges.

## 4. Count Data: Poisson & Negative-Binomial Regression

When modeling event counts $y_i \in \{0, 1, 2, \dots\}$, we use a log link:

$$
y_i \sim \operatorname{Poisson}(\mu_i), \quad \log(\mu_i) = \alpha + \beta x_i + \log(u_i)
$$

where $\log(u_i)$ is an **exposure offset** accounting for varying observation times or trap areas.

### Overdispersion and the Negative-Binomial Model
The Poisson model strictly enforces $\operatorname{Var}(Y) = \mathbb{E}[Y] = \mu$. In empirical social and biological data, unobserved heterogeneity causes **overdispersion** ($\operatorname{Var}(Y) > \mu$). 

To handle this, we use the **Negative-Binomial distribution**:

$$
y_i \sim \operatorname{NegBinomial}(\mu_i, \alpha_{\text{disp}}), \quad \operatorname{Var}(Y_i) = \mu_i + \alpha_{\text{disp}} \mu_i^2
$$

```python
with pm.Model() as roaches_negbin_model:
    alpha = pm.Normal("alpha", mu=2.0, sigma=1.0)
    beta_treat = pm.Normal("beta_treat", mu=0.0, sigma=0.5)
    phi = pm.Exponential("phi", 1.0) # dispersion parameter
    
    # Linear predictor with log exposure offset
    mu = pm.math.exp(alpha + beta_treat * treatment + pm.math.log(exposure_days))
    
    y_obs = pm.NegativeBinomial("y_obs", mu=mu, alpha=phi, observed=roach_counts)

```

## 5. Ordered Categorical Outcomes (Ordered Logit)

Survey responses (e.g., "strongly disagree" to "strongly agree", ratings $1, 2, \dots, K$) are ordered but **not equally spaced** interval variables. 

The **Ordered Logistic model** assumes an underlying continuous latent propensity $z_i = X_i \beta + \epsilon_i$, partitioned by $K-1$ ordered cutpoints $c_1 < c_2 < \dots < c_{K-1}$:

$$
P(Y_i \le k) = \operatorname{logit}^{-1}(c_k - X_i \beta)
$$

$$
P(Y_i = k) = P(Y_i \le k) - P(Y_i \le k - 1)
$$

This guarantees that categories reflect discrete threshold crossings without imposing artificial numerical linearity.

## 6. Statistical Decisions, Probabilities & Cost Matrices

Following [Sergey Nikolenko](https://www.sergeynikolenko.ru/) (*07_statdecision*), obtaining posterior class probabilities $P(y=1 \mid x)$ is only the first half of Bayesian inference. Making an optimal decision $a \in \{0, 1\}$ requires integrating probabilities with a **Loss / Cost Matrix** $L(a, y)$:

$$
\mathbb{E}[\operatorname{Loss}(a=1)] = L(1, 0) \cdot P(y=0 \mid x) + L(1, 1) \cdot P(y=1 \mid x)
$$

The optimal classification threshold is not universally $0.50$; if false negatives are 10 times more costly than false positives, the optimal decision boundary shifts to $P^* = \frac{L(1, 0)}{L(1, 0) + L(0, 1)} = \frac{1}{11} \approx 0.091$.

---

## Key Takeaways

- GLMs separate the **systematic linear predictor** $\eta = X\beta$ from the **bounded observable mean** $\mu = g^{-1}(\eta)$.
- Logistic regression coefficients must be interpreted through **probability contrasts** $\Delta P$ or average predictive comparisons.
- Always check for **overdispersion** in count data; prefer Negative-Binomial when variance exceeds the mean.
- Ordered survey scales require **ordered threshold cutpoints**, avoiding arbitrary continuous numerical assignments.
