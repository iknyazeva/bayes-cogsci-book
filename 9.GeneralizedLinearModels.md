## 1. The Tripartite Architecture of GLMs

Standard linear regression assumes that outcomes are continuous, symmetric, unbounded, and have constant error variance ($\epsilon \sim \operatorname{Normal}(0, \sigma^2)$). In empirical psychology, cognitive science, and social sciences, empirical outcomes frequently violate every one of these assumptions:
- **Binary Choices**: Accuracy (Correct / Incorrect), Choice (Accept / Reject), Memory Recall ($y \in \{0, 1\}$).
- **Ordered Ratings**: Likert survey scales, confidence judgments, severity ratings ($y \in \{1, 2, \dots, K\}$).
- **Event Counts**: Fixation counts, saccade numbers, error frequencies ($y \in \{0, 1, 2, \dots\}$).
- **Waiting Times & Latencies**: Reaction times, reading durations, task completion latencies ($y \in \mathbb{R}^+$).

Nelder and Wedderburn (1972) unified all these models into the **Generalized Linear Model (GLM)** framework, consisting of three foundational components:

```
+-----------------------------------------------------------------------------------------------+
|                                 THE TRIPARTITE GLM FRAMEWORK                                  |
+-------------------------------+-------------------------------+-------------------------------+
|  1. Linear Predictor (η)      |  2. Link Function g(·)        |  3. Exponential Likelihood    |
|                               |                               |                               |
|  ηᵢ = α + β₁·x₁ᵢ + ... + βₖ·xₖᵢ|  Transforms mean μᵢ to ηᵢ:    |  p(yᵢ | θᵢ, φ) from           |
|                               |  ηᵢ = g(μᵢ) ⟺ μᵢ = g⁻¹(ηᵢ)   |  Exponential Dispersion Family|
+-------------------------------+-------------------------------+-------------------------------+
```

## 2. Taxonomy of Common GLM Families

| Model Family | Response Domain ($\mathcal{Y}$) | Link Function $g(\mu)$ | Inverse Link $\mu = g^{-1}(\eta)$ | Observable Interpretation |
|---|---|---|---|---|
| **Gaussian** | Continuous $\mathbb{R}$ | Identity: $\mu$ | $\mu = \eta$ | Additive expected value $\mathbb{E}[y]$ |
| **Logistic** | Binary $\{0, 1\}$ | Logit: $\log\left(\frac{\mu}{1-\mu}\right)$ | $\operatorname{logit}^{-1}(\eta) = \frac{1}{1 + e^{-\eta}}$ | Success probability $p = P(y=1)$ |
| **Ordered Logit** | Discrete $\{1, \dots, K\}$ | Cumulative Logit: $\text{logit}(P(y \le k))$ | $P(y \le k) = \frac{1}{1 + e^{-(c_k - \eta)}}$ | Likert category probability $P(y = k)$ |
| **Poisson** | Discrete counts $\mathbb{N}_0$ | Log: $\log(\mu)$ | $\mu = \exp(\eta)$ | Multiplicative event rate $\lambda$ |
| **Neg-Binomial** | Overdispersed $\mathbb{N}_0$ | Log: $\log(\mu)$ | $\mu = \exp(\eta)$ | Rate $\lambda$ with variance $\mu + \mu^2/\phi$ |
| **Exponential** *(Session 7)* | Positive duration $\mathbb{R}^+$ | Log: $\log(\lambda)$ | $\lambda = \exp(\eta)$ | Expected waiting time $\mathbb{E}[y] = 1/\lambda$ |

## 3. The Generative Forward Simulation Workflow for GLMs

In Bayesian GLMs, model validation begins **before looking at real data** by running forward simulations:
1. **Sample Parameters from Priors**: $\alpha \sim p(\alpha), \boldsymbol{\beta} \sim p(\boldsymbol{\beta})$.
2. **Compute Linear Predictor**: $\eta_i = \alpha + \sum \beta_j x_{ij}$.
3. **Map through Inverse Link**: $\mu_i = g^{-1}(\eta_i)$.
4. **Generate Observable Realizations**: $y_i \sim \text{Likelihood}(\mu_i)$.

If the prior on $\beta$ in a logistic regression is too wide (e.g., $\operatorname{Normal}(0, 100)$), the simulated probabilities $p_i = \text{logit}^{-1}(\eta_i)$ will be pushed to the extreme edges ($p \in \{0.00001, 0.99999\}$), producing an unrealistic bimodal prior predictive distribution. Scale-aware priors (e.g., $\operatorname{Normal}(0, 1.5)$) ensure that probability changes remain smooth and plausible across the predictor range.

````{dropdown} Concept Check: The Non-Linearity of Logit Odds
A logistic regression model reports a slope of $\beta = 0.8$ for education. Can you state that "each year of education increases the probability of switching by $0.8$"?

**Answer.** No. In logistic regression, $\beta$ represents a constant change on the **unbounded log-odds scale**, which corresponds to a multiplicative odds ratio $e^{0.8} \approx 2.23$. Because the inverse-logit function $p = 1 / (1 + e^{-\eta})$ is non-linear (S-shaped), the resulting change in probability depends heavily on the baseline risk:
- Near $p = 0.50$, $\Delta p \approx \beta / 4 = 0.20$ (20 percentage points).
- Near $p = 0.05$ or $p = 0.95$, the exact same $\beta = 0.8$ produces less than a 4 percentage point change in probability!
Reporting must always compute probability differences at explicit, meaningful covariate baselines.
````
