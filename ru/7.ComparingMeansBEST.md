# Дополнительно: модель BEST для оценивания различий групп

*Русская версия. [English version](/en/comparingmeansbest)*

## 1. Ограничения классического $t$-критерия Стьюдента

В экспериментальной психологии и эмпирических исследованиях двухвыборочный $t$-критерий Стьюдента — стандарт по умолчанию для сравнения двух групп. Однако у классического $t$-критерия есть три серьёзные проблемы:
1. **Предположение о нормальности**: данные в обеих группах считаются гауссовскими. Любые выбросы искажают выборочные средние и раздувают стандартные ошибки.
2. **Ловушка одинаковых дисперсий (гомоскедастичности)**: стандартный $t$-критерий предполагает $\sigma_1 = \sigma_2$. Хотя критерий Уэлча снимает это требование, он не даёт апостериорного распределения для отношения дисперсий.
3. **Ловушка дихотомии $p$-значений**: порог $p < 0.05$ говорит лишь о том, можно ли отвергнуть точечную нулевую гипотезу ($H_0: \mu_1 = \mu_2$), но **не сообщает величины эффекта**, точности оценки и того, насколько различие практически значимо.

Чтобы решить эти проблемы, Джон Крашке (2013) предложил подход **BEST (Bayesian Estimation Supersedes the $t$-Test)**.

---

## 2. Порождающая модель BEST

Вместо проверки бинарной гипотезы модель BEST оценивает совместное апостериорное распределение пяти параметров:
- **Положения групп**: $\mu_1, \mu_2$
- **Масштабы групп**: $\sigma_1, \sigma_2$ (разрешая разные дисперсии)
- **Параметр хвостов (число степеней свободы)**: $\nu$ (общий для двух групп)

$$
y_{i, 1} \sim t_\nu(\mu_1, \sigma_1), \quad y_{i, 2} \sim t_\nu(\mu_2, \sigma_2)
$$

```
               Структура порождения данных (BEST)
               
                 [ ν ~ Exp(1/29) + 1 ]
                       /       \
                      /         \
        [ μ₁ ~ Normal ]         [ μ₂ ~ Normal ]
        [ σ₁ ~ HalfNormal ]     [ σ₂ ~ HalfNormal ]
               |                       |
               v                       v
      y₁,ᵢ ~ t_ν(μ₁, σ₁)      y₂,ᵢ ~ t_ν(μ₂, σ₂)
```

### Априорные распределения, калиброванные по масштабу
Априорные распределения центрируются на объединённом среднем данных $\bar{y}_{\text{pool}}$ и стандартном отклонении $s_{\text{pool}}$:
- $\mu_1, \mu_2 \sim \operatorname{Normal}(\bar{y}_{\text{pool}}, \, 2 \cdot s_{\text{pool}})$
- $\sigma_1, \sigma_2 \sim \operatorname{HalfNormal}(2 \cdot s_{\text{pool}})$
- $\nu - 1 \sim \operatorname{Exponential}(\lambda = 1/29)$ *(большая часть массы вокруг $\nu \approx 30$, что соответствует почти нормальному распределению, но при необходимости позволяет хвостам стать тяжёлыми)*.

---

## 3. Содержательные контрасты на понятной шкале

По сэмплам апостериорного распределения мы вычисляем три производные величины:

1. **Разность средних**: $\Delta \mu = \mu_1 - \mu_0$
2. **Разность разбросов**: $\Delta \sigma = \sigma_1 - \sigma_0$
3. **Размер эффекта ($d$ Коэна)**:

$$
d = \frac{\mu_1 - \mu_0}{\sqrt{\frac{\sigma_0^2 + \sigma_1^2}{2}}}
$$

---

## 4. Принятие решений: интервал HDI и область ROPE

Чтобы принимать обоснованные решения без $p$-значений, Крашке предложил сопоставлять **область практической эквивалентности (ROPE)** и **95%-й интервал наибольшей плотности (HDI)**:

- **Определите ROPE**: диапазон вокруг нуля (например, $[-0.2, 0.2]$), в пределах которого различия считаются практически незначимыми.
- **Правила принятия решений**:
  1. **Отвергнуть нулевой эффект**: если весь 95% HDI для $\Delta \mu$ лежит **полностью вне ROPE** (например, $[1.5, 2.7]$).
  2. **Принять практическую эквивалентность**: если 95% HDI лежит **полностью внутри ROPE** (например, $[-0.05, 0.08]$).
  3. **Неопределённость (нужно больше данных)**: если 95% HDI пересекает границы ROPE.

```python
import pymc as pm
import arviz as az

with pm.Model() as best_model:
    # 1. Априорные распределения по объединённым данным
    mu_pool = df["value"].mean()
    sigma_pool = df["value"].std() * 2.0
    
    mu = pm.Normal("mu", mu=mu_pool, sigma=sigma_pool, shape=2)
    sigma = pm.HalfNormal("sigma", sigma=sigma_pool, shape=2)
    nu = pm.Exponential("nu_minus_one", 1/29.0) + 1.0
    
    # 2. Правдоподобие
    y_obs = pm.StudentT("y_obs", nu=nu, mu=mu[df["group_id"]], sigma=sigma[df["group_id"]], observed=df["value"])
    
    # 3. Детерминированные контрасты (Группа 1 - Группа 0)
    diff_means = pm.Deterministic("diff_means", mu[1] - mu[0])
    diff_sigmas = pm.Deterministic("diff_sigmas", sigma[1] - sigma[0])
    cohen_d = pm.Deterministic("cohen_d", diff_means / pm.math.sqrt((sigma[0]**2 + sigma[1]**2)/2.0))
    
    idata_best = pm.sample(draws=2000, tune=1000, target_accept=0.95)

# График с наложением ROPE
az.plot_posterior(idata_best, var_names=["diff_means", "cohen_d"], rope=[-0.2, 0.2], hdi_prob=0.95)
```

## Главные выводы

- Модель BEST заменяет жёсткие предположения классического $t$-критерия на **правдоподобие Стьюдента**, защищая выводы от выбросов и допуская разные разбросы ($\sigma_0 \neq \sigma_1$).
- Параметр $\nu$ позволяет данным самим определить толщину хвостов.
- Сочетание **HDI + ROPE** позволяет различить реальный эффект, практическую эквивалентность и статистическую неопределённость.
