# Итоговый кейс: просоциальное поведение шимпанзе

*Русская версия. [English version](/en/partialpoolingchimpanzees)*

## 1. Постановка эксперимента и исследовательский вопрос

В классическом эксперименте эволюционной антропологии Силк и соавторы (Silk et al., 2005; McElreath, *Statistical Rethinking*, гл. 11 и 13) исследовали фундаментальный вопрос когнитивной науки: **свойственны ли шимпанзе бескорыстные просоциальные предпочтения, если помощь сородичу не требует никаких личных затрат?**

### Экспериментальная установка с двумя рычагами
Шимпанзе (**актор**) сидит в клетке перед столом с двумя рычагами:
- **Эгоистичный выбор (1/0)**: нажатие этого рычага даёт 1 кусочек банана актору и 0 кусочков соседней клетке.
- **Просоциальный выбор (1/1)**: нажатие этого рычага даёт 1 кусочек банана актору и 1 кусочек соседней клетке.

Поскольку сам актор получает банан в любом случае, выбор просоциального рычага для него абсолютно **бесплатен**.

```
                           ПЛАН ЭКСПЕРИМЕНТА 2x2
                           
                 [ Контроль: партнёр отсутствует ]   [ Тест: партнёр присутствует ]
                 (condition = 0)                     (condition = 1)
               +-----------------------------------+-----------------------------------+
[ Блюда справа]| Условие 1 (prosoc_left = 0)       | Условие 3 (prosoc_left = 0)       |
               | Правый рычаг = 1/1 (Просоциальный)| Правый рычаг = 1/1 (Просоциальный)|
               | Левый рычаг  = 1/0 (Эгоистичный)  | Левый рычаг  = 1/0 (Эгоистичный)  |
               +-----------------------------------+-----------------------------------+
[ Блюда слева ]| Условие 2 (prosoc_left = 1)       | Условие 4 (prosoc_left = 1)       |
               | Левый рычаг  = 1/1 (Просоциальный)| Левый рычаг  = 1/1 (Просоциальный)|
               | Правый рычаг = 1/0 (Эгоистичный)  | Правый рычаг = 1/0 (Эгоистичный)  |
               +-----------------------------------+-----------------------------------+
```

### Структура данных
Датасет (`chimpanzees.csv`) содержит $N = 504$ пробы для $J = 7$ отдельных шимпанзе:
- `actor` $\in \{1, 2, \dots, 7\}$: идентификатор шимпанзе.
- `prosoc_left` $\in \{0, 1\}$: находилось ли просоциальное блюдо на левом рычаге ($1$) или на правом ($0$).
- `condition` $\in \{0, 1\}$: присутствовал ли партнёр в соседней клетке ($1$) или клетка была пустой ($0$, контроль).
- **Отклик ($y_i \in \{0, 1\}$, `pulled_left`)**: нажал ли актор левый рычаг ($1$) или правый ($0$).

## 2. Разведочный анализ: ловушка «Актора 2»

Посмотрим на долю нажатий левого рычага у каждого из 7 шимпанзе:

| Шимпанзе | Всего проб | Нажатий левого рычага | Доля $P(\text{Left})$ | Индивидуальная склонность |
|---|---|---|---|---|
| **Шимпанзе 1** | $72$ | $24$ | $33.3\%$ | Умеренно «праворукий» |
| **Шимпанзе 2** | $90$ | **$90$** | **$100.0\%$** | **Абсолютно «леворукий»** |
| **Шимпанзе 3** | $72$ | $20$ | $27.8\%$ | Сильно «праворукий» |
| **Шимпанзе 4** | $72$ | $24$ | $33.3\%$ | Умеренно «праворукий» |
| **Шимпанзе 5** | $72$ | $40$ | $55.6\%$ | Нейтральный / амбидекстр |
| **Шимпанзе 6** | $72$ | $42$ | $58.3\%$ | Нейтральный / амбидекстр |
| **Шимпанзе 7** | $72$ | $59$ | $81.9\%$ | Сильно «леворукий» |

```{caution}
**Ловушка Актора 2:**
Шимпанзе №2 нажимал левый рычаг **во всех 90 пробах из 90** ($100\%$).
- Если модель игнорирует индивидуальность обезьян (**полное объединение**), Актор 2 сильно исказит общее среднее вверх.
- Если оценивать Актора 2 совершенно независимо с плоскими априорными распределениями (**раздельные модели**), его оценка на логарифмической шкале улетит в $+\infty$, вызывая сбой оптимизатора.
- Только **частичное объединение (partial pooling)** мягко регуляризует Актора 2 за счёт популяционного распределения, оценивая реальную вариативность между особями.
```

## 3. Решение 1: полное объединение (Complete Pooling)

Модель предполагает, что все 7 шимпанзе абсолютно одинаковы и имеют один общий интерсепт $\alpha$:

$$
y_i \sim \operatorname{Bernoulli}(p_i), \quad \operatorname{logit}(p_i) = \alpha + \beta_{\text{treatment}[i]}
$$

```python
import pymc as pm
import pandas as pd
import numpy as np
import arviz as az

with pm.Model() as model_complete:
    alpha = pm.Normal("alpha", mu=0.0, sigma=1.5)
    beta = pm.Normal("beta", mu=0.0, sigma=1.0, shape=4)
    
    p = pm.math.invlogit(alpha + beta[df["treatment"] - 1])
    pm.Bernoulli("pulled_left", p=p, observed=df["pulled_left"])
    
    idata_complete = pm.sample(draws=2000, tune=1000, target_accept=0.95)
```

Эта модель недообучена: она полностью игнорирует тот факт, что разные шимпанзе предпочитают разные рычаги.

## 4. Решение 2: раздельные оценки (No Pooling)

Модель оценивает независимый интерсепт $\alpha_j$ для каждой обезьяны без связи между ними:

$$
y_i \sim \operatorname{Bernoulli}(p_i), \quad \operatorname{logit}(p_i) = \alpha_{\text{actor}[i]} + \beta_{\text{treatment}[i]}
$$

```python
with pm.Model() as model_no_pool:
    # 7 независимых интерсептов
    alpha = pm.Normal("alpha", mu=0.0, sigma=2.0, shape=7)
    beta = pm.Normal("beta", mu=0.0, sigma=1.0, shape=4)
    
    p = pm.math.invlogit(alpha[df["actor"] - 1] + beta[df["treatment"] - 1])
    pm.Bernoulli("pulled_left", p=p, observed=df["pulled_left"])
    
    idata_no_pool = pm.sample(draws=2000, tune=1000, target_accept=0.95)
```

## 5. Решение 3: частичное объединение (иерархическая логистическая модель)

Объединяем индивидуальные интерсепты общим распределением популяции шимпанзе, используя **нецентрированную параметризацию**, изученную на занятии 9:

$$
\alpha_j = \bar{\alpha} + \sigma_\alpha \cdot z_j, \quad z_j \sim \operatorname{Normal}(0, 1)
$$

```python
with pm.Model() as model_partial:
    # Гиперпараметры популяции
    a_bar = pm.Normal("a_bar", mu=0.0, sigma=1.5)
    sigma_a = pm.HalfNormal("sigma_a", sigma=1.5)
    
    # Нецентрированные индивидуальные отклонения
    z_a = pm.Normal("z_a", mu=0.0, sigma=1.0, shape=7)
    alpha = pm.Deterministic("alpha", a_bar + sigma_a * z_a)
    
    beta = pm.Normal("beta", mu=0.0, sigma=1.0, shape=4)
    
    p = pm.math.invlogit(alpha[df["actor"] - 1] + beta[df["treatment"] - 1])
    pm.Bernoulli("pulled_left", p=p, observed=df["pulled_left"])
    
    idata_partial = pm.sample(draws=2000, tune=1000, target_accept=0.95)
```

**Адаптивное сжатие в действии:**
- Для Актора 2 ($100\%$ нажатий) популяционное распределение работает как надёжный якорь: оценка $\alpha_2$ удерживается на разумном апостериорном уровне $+3.2$ ($\approx 96\%$ на шкале вероятностей), предотвращая уход в бесконечность.
- Межгрупповой разброс оценивается как $\sigma_\alpha \approx 1.34$, подтверждая наличие сильных индивидуальных предпочтений у обезьян.

## 6. Содержательный вывод: делятся ли шимпанзе едой?

Чтобы проверить, увеличивает ли присутствие партнёра долю просоциальных выборов, рассчитаем байесовские контрасты:

- **Когда просоциальное блюдо слева** (Условие 4 против Условия 2):
  $$
  \Delta_{\text{партнёр, слева}} = \beta_4 - \beta_2
  $$
- **Когда просоциальное блюдо справа** (Условие 3 против Условия 1):
  $$
  \Delta_{\text{партнёр, справа}} = \beta_3 - \beta_1
  $$

```python
beta_post = idata_partial.posterior["beta"]
delta_left = beta_post.sel(beta_dim_0=3) - beta_post.sel(beta_dim_0=1)
delta_right = beta_post.sel(beta_dim_0=2) - beta_post.sel(beta_dim_0=0)

print("Разность при просоциальном блюде слева:", delta_left.mean().values.round(3))
print("95% HDI:", az.hdi(delta_left, hdi_prob=0.95).values.round(3))
```

**Результаты:**
- $\Delta_{\text{партнёр, слева}} = +0.05$ ($95\%\text{ HDI } [-0.15, +0.25]$).
- $\Delta_{\text{партнёр, справа}} = -0.04$ ($95\%\text{ HDI } [-0.24, +0.16]$).

**Научный вывод:**
У шимпанзе выражены сильные индивидуальные предпочтения левой или правой руки ($\sigma_\alpha \approx 1.34$), но **нет никаких свидетельств просоциального намерения**. Наличие сородича за перегородкой не увеличило вероятность выбора щедрого рычага.

## Главные выводы

- **Полное объединение** недообучается, игнорируя реальную индивидуальность участников.
- **Раздельные модели** переобучаются на особях с предельными результатами ($100\%$ или $0\%$).
- **Частичное объединение** адаптивно сжимает экстремальные оценки к популяционному среднему $\operatorname{Normal}(\bar{\alpha}, \sigma_\alpha)$.
- **Нецентрированная параметризация** обеспечивает быструю и устойчивую работу MCMC без расходящихся переходов.
