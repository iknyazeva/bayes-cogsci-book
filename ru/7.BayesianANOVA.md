## 1. ANOVA как регрессия: единый подход на основе моделей

В традиционных курсах статистики дисперсионный анализ (ANOVA) часто преподносят как отдельный свод правил и $F$-критериев, основанных на разбиении сумм квадратов:

$$
\text{SS}_{\text{total}} = \text{SS}_{\text{between}} + \text{SS}_{\text{within}}
$$

В современном байесовском анализе ANOVA — это не отдельная философия, а просто **линейная регрессия с категориальными предикторами, индексацией условий и запланированными контрастами**.

### Преимущества байесовского взгляда:
1. **Разные дисперсии в группах (гетероскедастичность)**: классическая ANOVA строго требует равенства дисперсий во всех ячейках ($\sigma_1 = \sigma_2 = \sigma_3$). Если разброс в группах различается, классический $F$-тест завышает вероятность ложноположительных находок (ошибку I рода). В байесовской модели мы легко задаём индивидуальные стандартные отклонения $\sigma_j$ для каждой группы.
2. **Несбалансированные ячейки ($n_{jk} \neq n$)**: когда размеры выборок в группах не равны, классические суммы квадратов (Type I, II, III) выдают противоречивые результаты. Байесовский вывод даёт точное совместное апостериорное распределение независимо от баланса выборок.
3. **Контрасты без искусственных штрафов за множественность**: классические post-hoc критерии требуют консервативных поправок на множественные сравнения (Бонферрони, Тьюки), которые резко снижают статистическую мощность. В байесовской регрессии мы напрямую получаем полное апостериорное распределение для любого содержательного контраста.

## 2. Однофакторная модель: сравнение нескольких групп ($K \ge 3$)

Представьте эксперимент, где когнитивный показатель измеряется в $K = 4$ независимых условиях (например: Контроль, Низкая доза, Высокая доза, Поведенческая терапия):

$$
y_{ij} \sim \operatorname{Normal}(\mu_j, \sigma), \quad j = 1, \dots, K
$$

Вместо общего $F$-теста «различается ли хотя бы одна группа от остальных», мы напрямую оцениваем среднее значение в каждой группе $\mu_j$:

```python
import pymc as pm
import numpy as np
import arviz as az

with pm.Model() as oneway_anova:
    # Априорные распределения по объединённым данным
    mu_pool = df["value"].mean()
    sd_pool = df["value"].std() * 2.0
    
    # Вектор средних для каждой группы
    mu = pm.Normal("mu", mu=mu_pool, sigma=sd_pool, shape=n_groups)
    sigma = pm.HalfNormal("sigma", sigma=sd_pool)
    
    # Правдоподобие с групповым индексом
    y_obs = pm.Normal("y_obs", mu=mu[df["group_id"]], sigma=sigma, observed=df["value"])
    
    # Запланированные содержательные контрасты:
    diff_low_ctrl = pm.Deterministic("diff_low_ctrl", mu[1] - mu[0])
    diff_high_ctrl = pm.Deterministic("diff_high_ctrl", mu[2] - mu[0])
    diff_high_low = pm.Deterministic("diff_high_low", mu[2] - mu[1])
    
    idata_oneway = pm.sample(draws=2000, tune=1000)
```

Каждое парное сравнение сразу получает полное апостериорное распределение, интервал HDI и оценку величины эффекта на понятной шкале измерений.

## 3. Двухфакторные планы: параметризация средних по ячейкам

В эксперименте с двумя факторами (например, Фактор A с 2 уровнями и Фактор B с 3 уровнями) мы имеем $2 \times 3 = 6$ экспериментальных условий (ячеек).

### Ловушка классических dummy-переменных
Классические пакеты раскладывают отклик через фиктивные переменные:

$$
y_i = \mu_0 + \alpha_{\text{A}} + \beta_{\text{B}} + (\alpha\beta)_{\text{A} \times \text{B}} + \epsilon_i
$$

Программы накладывают искусственные ограничения вроде «сумма равна нулю» или выбирают опорную категорию, создавая сложную корреляцию между оценками главных эффектов и взаимодействий.

### Параметризация средних по ячейкам (Cell-Means, рекомендуется)
Вместо запутанных контрастных таблиц мы напрямую оцениваем **среднее для каждой ячейки** $\mu_j$ ($j = 1, \dots, 6$):

$$
y_i \sim \operatorname{Normal}(\mu_{\text{cell}[i]}, \sigma)
$$

```python
# Создаём индекс ячейки для каждой комбинации факторов
df["cell_idx"] = pd.factorize(df["factor_a"].astype(str) + "_" + df["factor_b"].astype(str))[0]
n_cells = 6

with pm.Model() as cell_means_model:
    mu_cells = pm.Normal("mu_cells", mu=df["value"].mean(), sigma=df["value"].std() * 2, shape=n_cells)
    sigma = pm.HalfNormal("sigma", sigma=df["value"].std())
    
    y_obs = pm.Normal("y_obs", mu=mu_cells[df["cell_idx"]], sigma=sigma, observed=df["value"])
    
    # Любой главный эффект или взаимодействие — простая линейная комбинация средних ячеек:
    contrast_simple = pm.Deterministic("contrast_simple", mu_cells[1] - mu_cells[0])
    
    idata_cells = pm.sample(draws=2000, tune=1000)
```

## Главные выводы

- Дисперсионный анализ — это **линейная регрессия с категориальными предикторами**.
- **Параметризация средних по ячейкам (cell-means)** прозрачна, избавляет от путаницы с опорными категориями и позволяет строить любые контрасты напрямую по сэмплам апостериорного распределения.
- Различия дисперсий в группах ($\sigma_j \neq \sigma_k$) в байесовском подходе учитываются естественно.
- При отчёте апостериорных распределений для запланированных контрастов поправки типа Бонферрони не требуются.
