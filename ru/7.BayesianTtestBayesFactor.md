# Дополнительно: проверка точечных гипотез и фактор Байеса

*Русская версия. [English version](/en/bayesianttestbayesfactor)*

## 1. Оценивание параметров против проверки гипотез

В байесовском анализе исследователи сталкиваются с двумя разными вопросами:
1. **Оценивание величины (неопределённость параметров)**: *«Какова наиболее вероятная величина различия $\delta$ и как выглядит 95%-й интервал неопределённости?»* (На этот вопрос отвечают апостериорное распределение, интервалы HDI и область ROPE).
2. **Проверка гипотез (сравнение моделей)**: *«Во сколько раз наблюдаемые данные более вероятны при наличии эффекта ($H_1: \delta \neq 0$), чем при его строгом отсутствии ($H_0: \delta = 0$)?»* (На этот вопрос отвечает **фактор Байеса**, Bayes Factor).

Когда мы сравниваем вложенные модели (например, нулевой эффект против произвольного эффекта), **отношение плотностей Сэвиджа–Дики (Savage–Dickey density ratio)** даёт точный и элегантный способ найти фактор Байеса без сложного вычисления многомерных интегралов.

---

## 2. Метод отношения плотностей Сэвиджа–Дики

Сравним две модели:
- **Нулевая гипотеза $H_0$**: $\delta = 0$ (строгое отсутствие эффекта).
- **Альтернативная гипотеза $H_1$**: $\delta \sim p(\delta \mid H_1)$ (эффект распределён в соответствии с априорным распределением).

Дики (1971) показал, что для вложенных моделей **фактор Байеса в пользу нулевой гипотезы ($\text{BF}_{01}$)** равен отношению **высоты апостериорной плотности в точке $\delta = 0$** к **высоте априорной плотности в точке $\delta = 0$**:

$$
\text{BF}_{01} = \frac{p(y \mid H_0)}{p(y \mid H_1)} = \frac{p(\delta = 0 \mid y, H_1)}{p(\delta = 0 \mid H_1)}
$$

Соответственно, фактор Байеса в пользу альтернативы равен обратной величине:

$$
\text{BF}_{10} = \frac{1}{\text{BF}_{01}} = \frac{p(\delta = 0 \mid H_1)}{p(\delta = 0 \mid y, H_1)}
$$

*Рисунок 7.3. Отношение плотностей Сэвиджа–Дики в действии. Слева (a): убедительные свидетельства в пользу эффекта ($H_1$) — апостериорное распределение сместилось далеко от нуля, высота в нуле упала почти до нуля, $\text{BF}_{10} \gg 100$. В центре (b): сильные свидетельства в пользу отсутствия эффекта ($H_0$) — апостериорная плотность сжалась ровно вокруг нуля, $\text{BF}_{01} > 8$. ### Шкала свидетельств Джеффриса

| $\text{BF}_{10}$ | Сила свидетельств в пользу $H_1$ против $H_0$ |
|---|---|
| $> 100$ | Решающие / исключительно сильные |
| $30 - 100$ | Очень сильные |
| $10 - 30$ | Сильные свидетельства |
| $3 - 10$ | Умеренные свидетельства |
| $1 - 3$ | Слабые / нерешительные свидетельства |
| $1$ | Нет свидетельств (данные одинаково вероятны при обеих гипотезах) |
| $< 1/3$ | Умеренные свидетельства в пользу $H_0$ (отсутствие эффекта) |
| $< 1/10$ | Сильные свидетельства в пользу $H_0$ |

## 3. Практический пример: эксперимент с этической клятвой

В исследовании Wagenmakers et al. (2010) проверялось, уменьшает ли подписание этической клятвы склонность к обману:
- **Подписавшие клятву**: $424$ честных ответа из $777$ ($54.6\%$).
- **Не подписывавшие**: $5416$ из $9072$ ($59.7\%$).

Проверим, равна ли разность долей $\delta = \theta_1 - \theta_2$ строго нулю ($H_0: \delta = 0$) или отлична от нуля:

```python
import pymc as pm
import numpy as np
from scipy.stats import gaussian_kde

with pm.Model() as pledge_model:
    theta1 = pm.Beta("theta1", alpha=1.0, beta=1.0)
    theta2 = pm.Beta("theta2", alpha=1.0, beta=1.0)
    delta = pm.Deterministic("delta", theta1 - theta2)
    
    pm.Binomial("s1_obs", n=777, p=theta1, observed=424)
    pm.Binomial("s2_obs", n=9072, p=theta2, observed=5416)
    
    idata = pm.sample(draws=4000, tune=2000, target_accept=0.95)

post_delta = idata.posterior["delta"].values.ravel()
prior_delta = np.random.beta(1, 1, 30000) - np.random.beta(1, 1, 30000)

kde_post = gaussian_kde(post_delta)
kde_prior = gaussian_kde(prior_delta)

bf01 = float(kde_post(0.0)) / float(kde_prior(0.0))
bf10 = 1.0 / bf01
print(f"BF01 = {bf01:.2f} | BF10 = {bf10:.2f}")
```

Результат: $\text{BF}_{10} \approx 2.22$. Данные дают лишь слабые, нерешительные свидетельства в пользу эффекта клятвы.

## 4. Парадокс Джеффриса–Линдли и чувствительность к априорным распределениям

```{warning}
**Факторы Байеса крайне чувствительны к ширине априорного распределения!**
В отличие от оценивания параметров (где 95% HDI практически не меняется от умеренного расширения априорного распределения при хорошей выборке), **фактор Байеса напрямую зависит от масштаба априорного распределения $p(\delta \mid H_1)$**.

Если задать неоправданно широкое «неинформативное» распределение вроде $\delta \sim \operatorname{Normal}(0, 1000)$, априорная плотность в нуле $p(\delta = 0 \mid H_1)$ упадёт почти до нуля. В результате отношение Сэвиджа–Дики $\text{BF}_{01} = \frac{p(0 \mid y)}{p(0 \mid H_1)}$ **искусственно улетит в бесконечность**, ложно заявляя об «абсолютном подтверждении нулевой гипотезы»!

**Рекомендация:** всегда используйте содержательно обоснованные априорные распределения единичной информации (например, распределение Коши со шкалой $0.707$) и всегда приводите график чувствительности фактора Байеса к ширине априорного распределения.
```

## Главные выводы

- Отношение плотностей **Сэвиджа–Дики** позволяет найти фактор Байеса для точечной гипотезы делением высоты апостериорной плотности на априорную в точке $\delta = 0$.
- Фактор Байеса сравнивает **предсказательную силу двух моделей**, а не просто оценивает параметр.
- Из-за парадокса Джеффриса–Линдли факторы Байеса требуют строгой проверки чувствительности к априорным распределениям.
