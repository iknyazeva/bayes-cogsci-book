## 1. Повторные измерения нарушают предположение о независимости

На занятиях 7 и 8 каждая строка таблицы представляла отдельного независимого человека (пара «мать–ребёнок» в KidIQ). Но в экспериментальной психологии, нейронауках и социологии данные почти никогда не бывают изолированными точками. Наблюдения естественным образом **сгруппированы в кластеры**:
- Множество проб на время реакции от **одного и того же участника**.
- Множество учеников внутри **одного класса или школы**.
- Множество пациентов, проходящих лечение в **одной клинике**.

Когда измерения повторяются, стандартная регрессия сталкивается с фундаментальной дилеммой:

```
+-----------------------------------------------------------------------------------------+
|                                    ДИЛЕММА ОБЪЕДИНЕНИЯ                                  |
+---------------------------------------------+-------------------------------------------+
| 1. Полное объединение (Complete Pooling)    | 2. Раздельные модели (No Pooling)         |
|                                             |                                           |
| Свалить все данные в одну общую прямую:     | Подогнать 18 совершенно независимых       |
| y_i = α + β·x_i + ε_i.                      | регрессий: y_ij = α_j + β_j·x_ij + ε_ij.  |
|                                             |                                           |
| Игнорирует индивидуальные различия.         | Для участников с малым числом проб        |
| Делает вид, что все N = 180 наблюдений —    | оценки получаются крайне шумными          |
| это разные люди, занижая реальную           | и переобученными под случайные            |
| неопределённость.                           | флуктуации выборки.                       |
+---------------------------------------------+-------------------------------------------+
```

**Иерархическое (многоуровневое) байесовское моделирование** разрешает эту дилемму через **частичное объединение (partial pooling)**: мы оцениваем индивидуальные параметры $\alpha_j$ для каждого участника, но предполагаем, что они порождены **общим популяционным распределением**.

### Модельная карточка: эксперимент по депривации сна (`sleepstudy`)

| Поле | Спецификация |
|---|---|
| **Исход** | Среднее время реакции в миллисекундах ($y \in \mathbb{R}^+$) |
| **Структура** | Лонгитюдные пробы: 10 измерений по дням для $J = 18$ участников ($N = 180$) |
| **Предиктор** | `Days` — день ограничения сна (от $0$ до $9$ дней по 3 часа сна в сутки) |
| **Главные величины** | Базовое время реакции в популяции $\mu_\alpha$, среднее замедление от недосыпа $\mu_\beta$ и индивидуальные траектории |
| **Модель наблюдений** | $y_{ij} \sim \operatorname{Normal}(\alpha_j + \beta_j \text{Days}_{ij}, \, \sigma)$ |
| **Иерархия** | Индивидуальные интерсепты $\alpha_j \sim \operatorname{Normal}(\mu_\alpha, \tau_\alpha)$ с нецентрированной параметризацией |
| **Цель** | Отделить общую уязвимость к потере сна от стабильных индивидуальных особенностей участников |

## 2. Обменность и адаптивное сжатие (shrinkage)

Предположим, что каждый участник $j$ имеет своё базовое время реакции $\alpha_j$. Мы рассматриваем участников как случайные выборки из общего популяционного распределения со средним $\mu_\alpha$ и межгрупповым разбросом $\tau$:

$$
\alpha_j \sim \operatorname{Normal}(\mu_\alpha, \tau), \quad j = 1, \dots, J
$$

$$
y_{ij} \sim \operatorname{Normal}(\alpha_j, \sigma), \quad i = 1, \dots, n_j
$$

Апостериорная оценка среднего для участника $j$ представляет собой взвешенный компромисс между выборочным средним этого участника $\bar{y}_j$ и средним по всей популяции $\mu_\alpha$:

$$
\hat{\alpha}_j = (1 - B_j) \bar{y}_j + B_j \mu_\alpha
$$

где **коэффициент сжатия $B_j \in [0, 1]$** равен:

$$
B_j = \frac{\frac{\sigma^2}{n_j}}{\frac{\sigma^2}{n_j} + \tau^2} = \frac{1}{1 + n_j \frac{\tau^2}{\sigma^2}}
$$

### Три правила адаптивного сжатия
1. **Размер группы ($n_j$)**: если у участника всего 3 пробы, погрешность измерения $\sigma^2 / n_j$ огромна. Модель сильно притягивает ($B_j \approx 1$) его оценку к общему среднему $\mu_\alpha$. Если же у участника 50 проб, сжатие практически незаметно.
2. **Различия между людьми ($\tau$)**: если люди кардинально отличаются друг от друга ($\tau \gg \sigma$), сжатие минимально. Если же все участники почти одинаковы ($\tau \approx 0$), модель автоматически стягивается к полному объединению.
3. **Заимствование силы (information borrowing)**: малые группы заимствуют статистическую надёжность у всей остальной выборки. Это предотвращает ложные сенсации из-за случайного шума.

## 3. Нецентрированная параметризация: спасение из воронки Нила

На занятии 6 мы познакомились с галереей неудачных запусков сэмплера. Одной из главных проблем была геометрия **воронки (funnel)** в задаче о восьми школах Рубина, где сэмплер NUTS выдавал более 200 расходящихся переходов (divergences). Теперь разберёмся, откуда они берутся и как их победить.

### Геометрическая ловушка
Когда межгрупповой разброс $\tau$ стремится к нулю, возможный диапазон значений $\alpha_j$ резко сжимается вокруг $\mu_\alpha$. В пространстве параметров $(\alpha_j, \tau)$ образуется узкое «горлышко» — **воронка Нила (Neal's Funnel)**. Траектория сэмплера не может протиснуться в эту узкую щель с резкой кривизной и порождает **расхождения (divergences)**.

```
                ВОРОНКА НИЛА
         τ  ^      \        /
            |       \  ••  /     <-- Широкая часть (легко сэмплировать)
            |        \ •  /
            |         \••/
            |          ||        <-- Узкое горлышко: MCMC выдаёт расхождения!
            +----------+---------> α_j
                       μα
```

### Решение: нецентрированное преобразование
Вместо того чтобы сэмплировать $\alpha_j$ напрямую из сужающегося распределения $\operatorname{Normal}(\mu_\alpha, \tau)$, мы сэмплируем независимые стандартные нормальные отклонения $z_j \sim \operatorname{Normal}(0, 1)$ и затем детерминированно масштабируем их:

$$\begin{array}{l|l}
\textbf{Центрированная (сбоит при малых данных)} & \textbf{Нецентрированная (надёжный MCMC без сбоев)} \\
\hline
\tau \sim \operatorname{HalfNormal}(s) & \tau \sim \operatorname{HalfNormal}(s) \\
\alpha_j \sim \operatorname{Normal}(\mu_\alpha, \tau) & z_j \sim \operatorname{Normal}(0, 1) \\
& \alpha_j = \mu_\alpha + \tau \cdot z_j \\
y_{ij} \sim \operatorname{Normal}(\alpha_j, \sigma) & y_{ij} \sim \operatorname{Normal}(\alpha_j, \sigma)
\end{array}$$

В нецентрированной параметризации $z_j$ и $\tau$ априорно абсолютно независимы. Геометрия параметров превращается в прямой цилиндр, и расходящиеся переходы исчезают!

```python
import pymc as pm
import numpy as np
import arviz as az

with pm.Model() as non_centered_sleep:
    # 1. Популяционные гиперпараметры
    mu_alpha = pm.Normal("mu_alpha", mu=250.0, sigma=30.0) # Базовое RT в популяции (~250 мс)
    tau_alpha = pm.HalfNormal("tau_alpha", sigma=30.0)      # Межгрупповой разброс между людьми
    sigma_y = pm.HalfNormal("sigma_y", sigma=25.0)          # Внутрипробный шум
    
    # 2. Нецентрированные индивидуальные отклонения
    z_alpha = pm.Normal("z_alpha", mu=0.0, sigma=1.0, shape=n_subjects)
    alpha = pm.Deterministic("alpha", mu_alpha + tau_alpha * z_alpha)
    
    # 3. Общий эффект по дням
    beta_days = pm.Normal("beta_days", mu=10.0, sigma=5.0)  # Замедление за день (мс/день)
    
    # 4. Условное среднее
```

## 4. Случайные интерсепты и случайные наклоны

В коде выше у каждого участника свой базовый уровень $\alpha_j$, но замедление по дням $\beta$ предполагается строго одинаковым для всех.

В реальности одни люди прекрасно переносят недостаток сна, а другие быстро теряют концентрацию. Мы можем разрешить **и интерсептам, и наклонам варьироваться для каждого участника**:

$$
\mu_{ij} = \alpha_j + \beta_j \text{Days}_{ij}
$$

В библиотеке **Bambi** такую модель можно записать формулой в привычном синтаксисе `lme4`:

```python
import bambi as bmb

# Модель со случайными интерсептами и наклонами по участникам
model_sleep = bmb.Model(
    "Reaction ~ Days + (Days | Subject)",
    data=sleep_df
)
idata_sleep = model_sleep.fit(draws=2000, tune=1000)
```

Bambi автоматически использует нецентрированную параметризацию и задаёт априорное распределение LKJ на корреляцию между базовой скоростью и чувствительностью к депривации.

## 5. Цели предсказания: знакомый участник против нового человека

При прогнозах в иерархических моделях необходимо точно понимать, для кого строится предсказание:

1. **Предсказание для уже наблюдаемого участника ($j$)**:
   Мы используем его собственные параметры из апостериорного распределения $\alpha_j^{(s)}$:

   $$
   \widetilde{y}_{j, \text{new}}^{(s)} \sim \operatorname{Normal}(\alpha_j^{(s)} + \beta_j^{(s)} \text{Days}^*, \, \sigma^{(s)})
   $$

   Этот прогноз учитывает индивидуальные особенности именно этого человека.

2. **Предсказание для нового, ранее не виданного участника**:
   Мы не знаем, где окажется новый человек. Поэтому мы сэмплируем новое значение из популяционного гиперраспределения:

   $$
   \alpha_{\text{new}}^{(s)} \sim \operatorname{Normal}(\mu_\alpha^{(s)}, \tau_\alpha^{(s)}), \quad \widetilde{y}_{\text{new}}^{(s)} \sim \operatorname{Normal}(\alpha_{\text{new}}^{(s)} + \beta_{\text{new}}^{(s)} \text{Days}^*, \, \sigma^{(s)})
   $$

   Такой интервал предсказания будет существенно шире, поскольку он включает в себя вариативность всей популяции людей $\tau$.

## Главные выводы

- Иерархические модели обеспечивают **оптимальное адаптивное сжатие**, защищая от недообучения (полное объединение) и переобучения (раздельные модели).

- **Нецентрированная параметризация** устраняет расходящиеся переходы в воронке Нила при умеренных и малых размерах групп.
