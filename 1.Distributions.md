# Probability Distributions Tutorial

This tutorial reviews common probability distributions, both **discrete** and **continuous**. For each distribution, we provide its definition, probability function, expected value, and variance (when they exist). Understanding these is fundamental for statistics and probability theory.

Probability distributions are the building blocks of Bayesian models. We use them to describe two things: how we think **data** are generated (the likelihood) and what we **believe** about unknown parameters before seeing data (the prior). Different cognitive phenomena call for different distributional assumptions — response accuracy suggests a Binomial, reaction times an ExGaussian, neural spike counts a Poisson. Choosing the right distribution is one of the most important modelling decisions you will make.


## 1. Discrete Distributions

### 1.1 Discrete Uniform
A discrete uniform distribution assigns equal probability to $N$ outcomes.

$$
X \sim \text{Uniform}(N)
$$

$$
P(X = x \mid N) = \frac{1}{N}, \quad x = 1, 2, \dots, N
$$

- **Expected Value:** $E[X] = \frac{N + 1}{2}$
- **Variance:** $\text{Var}(X) = \frac{N^2 - 1}{12}$

Example: Rolling a fair six-sided die ($N=6$).

```{admonition} In Cognitive Science
:class: tip
The discrete uniform is the **null model for random guessing** in an N-alternative forced choice (N-AFC) task. If a participant is choosing randomly among $N = 4$ options, each has probability $\tfrac{1}{4}$. Performance significantly above $\tfrac{1}{N}$ indicates that the participant is using information from the stimulus.
```


### 1.2 Bernoulli
Models a binary outcome (success/failure).

$$
X \sim \text{Bern}(p)
$$

$$
P(X = x \mid p) = p^x (1 - p)^{1 - x}, \quad x \in \{0, 1\}
$$

- **Expected Value:** $E[X] = p$
- **Variance:** $\text{Var}(X) = p(1 - p)$

```{admonition} In Cognitive Science
:class: tip
Each **single trial** in a cognitive experiment often has a Bernoulli outcome: correct/incorrect in a recognition memory test, hit/miss in a signal detection task, recalled/not recalled in a free recall study. The parameter $p$ is the probability of "success" on any given trial.
```


### 1.3 Binomial
Counts the number of successes in $n$ independent Bernoulli trials.

$$
Y \sim \text{Binom}(n, p)
$$

$$
P(Y = y \mid n, p) = \binom{n}{y} p^y (1 - p)^{n - y}, \quad y = 0, \dots, n
$$

- **Expected Value:** $E[Y] = np$
- **Variance:** $\text{Var}(Y) = np(1 - p)$

```{admonition} In Cognitive Science
:class: tip
If a participant completes $n = 50$ recognition memory trials, the total **number of correct responses** follows a Binomial distribution (assuming independent trials with constant accuracy $p$). The Binomial is also used to model the number of "yes" responses in old/new recognition paradigms, or the number of correct identifications in a lineup task.
```


### 1.4 Poisson
Models the count of events occurring at a rate $\lambda > 0$.

$$
X \sim \text{Pois}(\lambda)
$$

$$
P(X = x \mid \lambda) = \frac{\lambda^x e^{-\lambda}}{x!}, \quad x = 0, 1, \dots
$$

- **Expected Value:** $E[X] = \lambda$
- **Variance:** $\text{Var}(X) = \lambda$

```{admonition} In Cognitive Science
:class: tip
The Poisson distribution models **count data** with no fixed upper bound. Common applications in cognitive neuroscience include: the number of **neural spikes** in a fixed time window, the number of **eye fixations** on a region of interest in a reading study, and the number of **errors** in a sustained attention task (e.g., continuous performance test).
```


## 2. Continuous Distributions

### 2.1 Normal (Gaussian)
The most widely used continuous distribution.

$$
X \sim \mathcal{N}(\mu, \sigma^2)
$$

$$
f(x \mid \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
$$

- **Expected Value:** $E[X] = \mu$
- **Variance:** $\text{Var}(X) = \sigma^2$

```{admonition} In Cognitive Science
:class: tip
The Normal distribution appears throughout cognitive science: **IQ scores** are defined to be Normal ($\mu=100$, $\sigma=15$), **EEG amplitudes** are often approximately Normal, and the **fMRI BOLD signal** is modelled as Normal noise around a predicted hemodynamic response. The Central Limit Theorem also makes the Normal distribution a natural approximation for means of many observations — which is why it underlies so many standard statistical tests.
```


### 2.2 Exponential
Models waiting times between events in a Poisson process.

$$
X \sim \text{Exp}(\lambda), \quad \lambda > 0
$$

$$
f(x \mid \lambda) = \lambda e^{-\lambda x}, \quad x \geq 0
$$

- **Expected Value:** $E[X] = \frac{1}{\lambda}$
- **Variance:** $\text{Var}(X) = \frac{1}{\lambda^2}$

```{admonition} In Cognitive Science
:class: tip
The Exponential distribution models **inter-event times** when events occur at a constant rate. Applications include: **inter-spike intervals** in neural recordings (under constant-rate firing assumptions), the time between successive **eye blinks**, and waiting times until the first response in a free-recall paradigm. Its "memoryless" property — the probability of an event in the next moment doesn't depend on how long you've already waited — is a useful null hypothesis for neural and behavioral timing data.
```


### 2.3 Beta

The Beta distribution is defined on the interval $[0, 1]$, making it ideal for modelling **probabilities and proportions**.

$$
X \sim \text{Beta}(\alpha, \beta)
$$

$$
f(x \mid \alpha, \beta) = \frac{\Gamma(\alpha + \beta)}{\Gamma(\alpha)\Gamma(\beta)} x^{\alpha-1}(1-x)^{\beta-1}, \quad 0 \leq x \leq 1
$$

- **Expected Value:** $E[X] = \frac{\alpha}{\alpha + \beta}$
- **Variance:** $\text{Var}(X) = \frac{\alpha \beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$

Special case: $\text{Beta}(1, 1) = \text{Uniform}(0, 1)$.

```{admonition} In Cognitive Science
:class: tip
The Beta distribution is the **conjugate prior** for the Bernoulli and Binomial likelihoods (see {doc}`3.ConjugatePriors`). In cognitive modelling, it is used as a prior for accuracy rates, recall probabilities, and proportions of "yes" responses. The parameters $\alpha$ and $\beta$ can be interpreted as "pseudo-counts" of prior successes and failures, making the Beta distribution highly intuitive for encoding prior knowledge.
```


### 2.4 Gamma

The Gamma distribution is defined on $(0, \infty)$ and is used for modelling positive continuous quantities.

$$
X \sim \text{Gamma}(\alpha, \beta)
$$

$$
f(x \mid \alpha, \beta) = \frac{\beta^\alpha}{\Gamma(\alpha)} x^{\alpha-1} e^{-\beta x}, \quad x > 0
$$

- **Expected Value:** $E[X] = \frac{\alpha}{\beta}$
- **Variance:** $\text{Var}(X) = \frac{\alpha}{\beta^2}$

```{admonition} In Cognitive Science
:class: tip
The Gamma distribution is the **conjugate prior** for the Poisson rate parameter $\lambda$ (see {doc}`3.ConjugatePriors`). In neuroscience, it models **neural firing rates** and is also used as a prior for precision (inverse variance) parameters in hierarchical Bayesian models. The Chi-Squared and Exponential distributions are both special cases of the Gamma.
```


### 2.5 Chi-Squared
Special case of the Gamma distribution, used in hypothesis testing.

$$
X \sim \chi^2(k)
$$

$$
f(x \mid k) = \frac{1}{2^{k/2}\Gamma(k/2)} x^{k/2 - 1} e^{-x/2}, \quad x \geq 0
$$

- **Expected Value:** $E[X] = k$
- **Variance:** $\text{Var}(X) = 2k$

```{admonition} In Cognitive Science
:class: tip
The Chi-Squared distribution is most familiar from **goodness-of-fit tests** for categorical data — for example, testing whether the distribution of response categories in a cognitive experiment matches a theoretical model. It is a special case of $\text{Gamma}(k/2, 1/2)$.
```


### 2.6 Cauchy
A heavy-tailed distribution without finite mean or variance.

$$
X \sim \text{Cauchy}(x_0, \gamma)
$$

$$
f(x \mid x_0, \gamma) = \frac{1}{\pi \gamma \left[1 + \left(\frac{x - x_0}{\gamma}\right)^2\right]}
$$

- **Expected Value:** undefined
- **Variance:** undefined

```{admonition} In Cognitive Science
:class: tip
The Cauchy distribution is used as a **weakly informative prior** in Bayesian hypothesis testing. For instance, the JZS Bayes factor for comparing two means (Rouder et al., 2009) places a Cauchy prior on the standardized effect size. Its heavy tails allow for the possibility of large effects while concentrating most prior mass near zero.
```


### 2.7 Half-Cauchy
Used as a prior for scale parameters in Bayesian statistics.

$$
X \sim \text{Half-Cauchy}(\gamma), \quad x > 0
$$

$$
f(x \mid \gamma) = \frac{2}{\pi \gamma \left(1 + \left(\frac{x}{\gamma}\right)^2\right)}
$$

- **Expected Value:** undefined
- **Variance:** undefined

```{admonition} In Cognitive Science
:class: tip
The Half-Cauchy is a recommended **weakly informative prior for standard deviation (scale) parameters** in hierarchical Bayesian models (Gelman, 2006). When modelling between-subject variability in cognitive experiments — such as differences in learning rates or baseline reaction times across participants — the Half-Cauchy prior provides regularization without being overly restrictive.
```


### 2.8 Exponentially Modified Gaussian (ExGaussian)
A convolution of a normal and an exponential distribution. Used to model response times.

$$
X \sim \text{ExGaussian}(\mu, \sigma, \lambda)
$$

PDF (no closed simple form; involves convolution).

- **Expected Value:** $E[X] = \mu + \frac{1}{\lambda}$
- **Variance:** $\text{Var}(X) = \sigma^2 + \frac{1}{\lambda^2}$

```{admonition} In Cognitive Science
:class: tip
The ExGaussian is the **standard parametric model for response time (RT) distributions** in cognitive psychology (Luce, 1986). The Gaussian component ($\mu$, $\sigma$) captures the bulk of the RT distribution — often interpreted as the "decision" component — while the exponential tail ($1/\lambda$) captures slow responses from attentional lapses, memory retrieval delays, or motor preparation variability. Changes in the exponential parameter $\tau = 1/\lambda$ are often associated with conditions that increase cognitive load or executive demand (e.g., Stroop interference, task switching).
```


## Choosing a Distribution: Quick Guide

```{tip}
When building a model, the choice of distribution should be guided by the **nature of the data**:

| Data type | Typical distribution |
|-----------|---------------------|
| Binary outcome per trial (correct/incorrect) | Bernoulli |
| Number of successes out of $n$ trials | Binomial |
| Count data with no upper bound (spikes, errors, fixations) | Poisson |
| Continuous, roughly symmetric | Normal |
| Positive continuous, right-skewed | Exponential, Gamma |
| Response times | ExGaussian (or shifted LogNormal) |
| Probability or proportion (parameter) | Beta |
| Positive rate or precision (parameter) | Gamma |
| Scale / standard deviation (parameter) | Half-Cauchy |
```
