# Session 5: Simulation, Parameter Recovery and Research Design

## 1. Simulation-Based Research Design (SBRD)

In classical statistics, research planning is often reduced to a ritualistic "sample size calculation" aimed at achieving 80% statistical power against a zero null hypothesis ($H_0: \theta = 0$).

In modern Bayesian practice, research design is conducted via **Simulation-Based Research Design (SBRD)**. Before collecting empirical data or recruiting human subjects, we simulate the entire research process forward:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                   THE SIMULATION-BASED DESIGN PIPELINE                      │
│ ─────────────────────────────────────────────────────────────────────────── │
│  1. Hypothesize Plausible Parameters:       θ_true ~ Prior / Grid           │
│  2. Forward Simulate Synthetic Datasets:   y_sim ~ DGP(θ_true, Design)      │
│  3. Fit Model / Estimator:                 θ_hat, 95% Credible Interval     │
│  4. Evaluate Recovery & Diagnostics:       Bias, Coverage, Type S, Type M   │
│  5. Optimize Design Allocation:            Participants (J) vs Trials (K)   │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. Parameter Recovery and the Diagonal Plot

An essential sanity check for any statistical workflow is **Parameter Recovery**: can your model accurately recover known generating values across repeated simulations?

### The Parameter Recovery Protocol:
1. Choose a grid of known true parameter values: $\theta_{\text{true}} \in [-1.0, 1.0]$.
2. For each $\theta_{\text{true}}$, simulate a synthetic dataset $y_{\text{sim}} \sim p(y \mid \theta_{\text{true}})$.
3. Fit the Bayesian model and extract the posterior mean $\hat{\theta}$ and $95\%$ credible interval $[L, U]$.
4. Plot $\hat{\theta}$ against $\theta_{\text{true}}$ on a scatter plot:

```
    Estimated θ_hat
          ^
      1.0 |           /  (Points hug the 45° line)
          |         / •
      0.5 |       / • •
          |     / • •
      0.0 |   / • •
          | / •
     -0.5 +---------------------> True θ_true
           -0.5  0.0  0.5  1.0
```

* **Unbiased Recovery**: The points should scatter symmetrically along the $45^\circ$ diagonal ($y = x$).
* **Shrinkage Awareness**: With regularizing priors in small samples, estimates will be slightly shrunk toward the prior mean; this is expected Bayesian shrinkage, not a programming bug.

## 3. Calibration and Empirical Coverage

A Bayesian $95\%$ credible interval is well-calibrated if, across repeated experiments drawn from the generative model, it contains the true parameter in exactly $95\%$ of cases:

$$\text{Empirical Coverage} = \frac{1}{M} \sum_{m=1}^M \mathbb{I}\left( L^{(m)} \le \theta_{\text{true}}^{(m)} \le U^{(m)} \right) \approx 0.95$$

* If your $95\%$ interval covers the true value only $80\%$ of the time, the model is **overconfident** (e.g. failing to account for clustering or unobserved heterogeneity).
* If your $95\%$ interval covers the true value $99\%$ of the time, the model is **underconfident / overly conservative**.

## 4. Beyond Power: Type S (Sign) and Type M (Exaggeration) Errors

Following Gelman & Carlin (2014) (*ROS* Chapter 16), relying on statistical significance ($p < 0.05$ or $95\%$ CI excluding 0) in noisy, underpowered studies creates severe systematic distortion:

### 1. Type S (Sign) Error:
The probability that a statistically significant estimate has the **wrong sign** (pointing in the opposite direction of truth):

$$\text{Type S} \equiv \mathbb{P}\left( \text{sgn}(\hat{\theta}) \neq \text{sgn}(\theta_{\text{true}}) \;\middle|\; |\hat{\theta}/\text{SE}| > 1.96 \right)$$

### 2. Type M (Magnitude / Exaggeration) Ratio:
The expected factor by which a statistically significant estimate **overestimates** the true effect magnitude:

$$\text{Type M} \equiv \mathbb{E}\left[ \left. \frac{|\hat{\theta}|}{|\theta_{\text{true}}|} \;\right|\; |\hat{\theta}/\text{SE}| > 1.96 \right]$$

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         THE WINNER'S CURSE (TYPE M)                         │
│ ─────────────────────────────────────────────────────────────────────────── │
│ In an underpowered study (N=30, True θ = 0.15, SE = 0.20):                  │
│ • Power is only 12%.                                                        │
│ • Type S error is 16%: 1 out of 6 "significant" findings claims the wrong  │
│   direction!                                                                │
│ • Type M exaggeration ratio is 2.8×: statistically significant published    │
│   estimates will claim effect sizes nearly THREE TIMES larger than reality! │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. The Interaction Sample Size Penalty

A common mistake in experimental design is adding an interaction term to a study designed for main effects:

$$y_i = \beta_0 + \beta_1 X_{1i} + \beta_2 X_{2i} + \beta_3 (X_{1i} \times X_{2i}) + \epsilon_i$$

For balanced binary treatments ($X_1, X_2 \in \{0, 1\}$):

$$\text{Var}(\hat{\beta}_1) = \frac{4\sigma^2}{N}, \quad \text{Var}(\hat{\beta}_3) = \frac{16\sigma^2}{N} = 4 \times \text{Var}(\hat{\beta}_1)$$

$$\text{SE}(\hat{\beta}_3) = 2 \times \text{SE}(\hat{\beta}_1)$$

:::{important}
**The Quadruple Sample Size Rule**:  
Because the standard error of an interaction is **twice as large** as the standard error of a main effect, detecting an interaction with the same precision requires at least **FOUR TIMES ($4\times$) the sample size**. If the interaction effect magnitude is smaller than the main effect, it can easily require **SIXTEEN TIMES ($16\times$)** the sample size!
:::

## 6. Clustered Allocations: Participants ($J$) vs. Trials ($K$)

In cognitive science and organizational research, data is hierarchically clustered (e.g. $K$ trials per participant across $J$ participants):

$$y_{jk} = \mu + \alpha_j + \epsilon_{jk}, \quad \alpha_j \sim \mathcal{N}(0, \sigma_{\text{person}}^2), \quad \epsilon_{jk} \sim \mathcal{N}(0, \sigma_{\text{trial}}^2)$$

The standard error of the estimated grand mean is:

$$\text{SE}(\hat{\mu}) = \sqrt{\frac{\sigma_{\text{person}}^2}{J} + \frac{\sigma_{\text{trial}}^2}{J \times K}}$$

### Design Implication:
* As $K \to \infty$, the trial-level noise term $\frac{\sigma_{\text{trial}}^2}{JK} \to 0$, but the standard error hits an impassable floor:
  $$\lim_{K \to \infty} \text{SE}(\hat{\mu}) = \frac{\sigma_{\text{person}}}{\sqrt{J}}$$
* If between-person variation $\sigma_{\text{person}}$ is large, adding more trials $K$ yields rapidly diminishing returns. The only way to increase precision is to recruit **more participants ($J$)**.

````{dropdown} 📝 Exercise 1: Calculating Type S and Type M Errors (Click to expand solution)
**Question**: A social psychology experiment tests an intervention with true effect size $\theta_{\text{true}} = 0.10$. Due to small sample size ($N = 25$), the standard error is $\text{SE} = 0.20$.
1. What is the $Z$-statistic threshold for statistical significance ($|\hat{\theta}| > 1.96 \times 0.20 = 0.392$)?
2. Compute the probability of finding a statistically significant result (statistical power).
3. Compute the Type S error probability and Type M exaggeration ratio.

**Solution & Step-by-Step Derivation**:
1. **Sampling Distribution**: $\hat{\theta} \sim \mathcal{N}(0.10, 0.20^2)$.
2. **Statistical Power**:
   * Significant positive: $\mathbb{P}(\hat{\theta} > 0.392) = 1 - \Phi\left(\frac{0.392 - 0.10}{0.20}\right) = 1 - \Phi(1.46) \approx 1 - 0.9279 = \mathbf{0.0721}$ ($7.2\%$).
   * Significant negative (Type S error): $\mathbb{P}(\hat{\theta} < -0.392) = \Phi\left(\frac{-0.392 - 0.10}{0.20}\right) = \Phi(-2.46) \approx \mathbf{0.0069}$ ($0.7\%$).
   * **Total Power**: $0.0721 + 0.0069 = \mathbf{0.0790}$ ($7.9\%$).
3. **Type S and Type M Errors**:
   * **Type S Error Rate**: $\frac{0.0069}{0.0721 + 0.0069} = \frac{0.0069}{0.0790} \approx \mathbf{8.7\%}$. (Almost 1 out of 11 significant findings is in the wrong direction!).
   * **Expected Significant Estimate Magnitude**: $\approx 0.44 \implies \text{Type M Exaggeration Ratio} = \frac{0.44}{0.10} \approx \mathbf{4.4\times}$.
*Conclusion*: Any significant finding published from this design will claim an effect size more than **4 times larger than reality**.
````

````{dropdown} 📝 Exercise 3: Optimizing Cognitive Design Allocation (Click to expand solution)
**Question**: A cognitive reaction time experiment has between-person standard deviation $\sigma_{\text{person}} = 80\text{ ms}$ and within-person trial noise $\sigma_{\text{trial}} = 120\text{ ms}$. 
1. Compare the standard error under Design A ($J = 20\text{ participants}, K = 100\text{ trials}$) versus Design B ($J = 50\text{ participants}, K = 20\text{ trials}$).
2. Both designs record a total of $20 \times 100 = 50 \times 20 = 1,000$ total trials. Which design achieves higher precision?

**Solution**:
1. **Design A ($J = 20, K = 100$)**:
   $$\text{SE}_A = \sqrt{\frac{80^2}{20} + \frac{120^2}{20 \times 100}} = \sqrt{\frac{6400}{20} + \frac{14400}{2000}} = \sqrt{320 + 7.2} = \sqrt{327.2} \approx \mathbf{18.09\text{ ms}}$$
2. **Design B ($J = 50, K = 20$)**:
   $$\text{SE}_B = \sqrt{\frac{80^2}{50} + \frac{120^2}{50 \times 20}} = \sqrt{\frac{6400}{50} + \frac{14400}{1000}} = \sqrt{128 + 14.4} = \sqrt{142.4} \approx \mathbf{11.93\text{ ms}}$$
*Conclusion*: For the exact same experimental trial budget ($1,000$ trials), **Design B is $34\%$ more precise** ($\text{SE} = 11.93\text{ ms}$ vs $18.09\text{ ms}$) because it allocates resources toward sampling more participants ($J$) rather than over-sampling trials ($K$).
````

## 8. Concept Check

````{dropdown} ❓ What is the difference between statistical power and Type M error?
Statistical power is the probability of obtaining $p < 0.05$ given that the true effect is non-zero. **Type M error** measures the conditional exaggeration factor: when a study *does* achieve significance, by what multiple does the sample estimate overestimate the true effect size?
````

````{dropdown} ❓ Why can't we fix small sample size J by running 1,000 trials per participant?
Because trial noise $\frac{\sigma_{\text{trial}}^2}{JK}$ vanishes as $K \to \infty$, but between-person sampling variability $\frac{\sigma_{\text{person}}^2}{J}$ remains fixed. You cannot learn about a population of individuals by measuring the same small group of individuals infinitely many times.
````

````{dropdown} ❓ Why do interaction effects require quadrupled sample size?
Because an interaction is a difference between two differences, combining variance from four subgroup cells ($2 \times 2$). The resulting standard error is $\text{SE}(\hat{\beta}_3) = 2 \times \text{SE}(\hat{\beta}_1)$, which requires $2^2 = 4\times$ the sample size to achieve equal precision.
````
