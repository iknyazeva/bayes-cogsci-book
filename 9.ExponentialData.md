# Duration & Waiting-Time GLMs (Exponential Data)

## 1. Modeling Continuous Positive Durations

In cognitive and behavioral experiments, time measurements are strictly positive ($y > 0$) and inherently right-skewed:
- Fixation durations during visual search.
- Inter-response intervals (IRIs) in sequential motor tapping tasks.
- Latency to first saccade or decision initiation.

The **Exponential distribution** is the fundamental maximum entropy model for waiting times of memoryless Poisson point processes:

$$
y_i \sim \operatorname{Exponential}(\lambda_i), \quad f(y_i \mid \lambda_i) = \lambda_i e^{-\lambda_i y_i}, \quad y_i > 0
$$

The expected waiting time is inversely related to the event rate: $\mathbb{E}[y_i] = \frac{1}{\lambda_i}$.

---

## 2. GLM Parameterization with Log-Link

To model how experimental covariates $x$ affect event rates, we use a **logarithmic link function** to enforce strictly positive rates $\lambda_i > 0$:

$$
\log(\lambda_i) = \alpha + \beta x_i \implies \lambda_i = \exp(\alpha + \beta x_i)
$$

Under this log-rate parameterization, the expected duration is:

$$
\mathbb{E}[y_i \mid x_i] = \frac{1}{\lambda_i} = \exp\left(-(\alpha + \beta x_i)\right)
$$

## 3. Forward Data Simulation and PyMC Implementation

We simulate $N = 150$ trial completion latencies as a function of cognitive task difficulty $x \in [-1.5, 1.5]$:

```python
import numpy as np
import pymc as pm
import arviz as az

# 1. Forward Simulation of Observable Durations
np.random.seed(42)
N = 150
x_sim = np.random.uniform(-1.5, 1.5, N)

alpha_true = 0.5
beta_true = -0.7  # Higher difficulty -> lower rate -> longer duration

# Rate lambda_i = exp(alpha + beta * x)
rates_true = np.exp(alpha_true + beta_true * x_sim)
y_sim = np.random.exponential(scale=1.0 / rates_true)

# 2. PyMC Model
with pm.Model() as exponential_glm:
    # Priors on log-rate intercept and slope
    alpha = pm.Normal("alpha", mu=0.0, sigma=1.5)
    beta = pm.Normal("beta", mu=0.0, sigma=1.5)
    
    # Log-link rate
    log_lam = alpha + beta * x_sim
    lam = pm.Deterministic("lam", pm.math.exp(log_lam))
    
    # Expected duration
    expected_duration = pm.Deterministic("expected_duration", 1.0 / lam)
    
    # Likelihood
    y_obs = pm.Exponential("y_obs", lam=lam, observed=y_sim)
    
    idata_exp = pm.sample(draws=2000, tune=1000, target_accept=0.95)

az.summary(idata_exp, var_names=["alpha", "beta"])
```

## 4. Coefficient Interpretation: Rates vs. Durations

- **Rate Interpretation**: A 1-unit increase in $x$ multiplies the event completion rate $\lambda$ by $e^\beta$. If $\beta = -0.7$, $e^{-0.7} \approx 0.50$ (the event rate is halved).
- **Duration Interpretation**: Because expected duration is $\frac{1}{\lambda} = e^{-\alpha - \beta x}$, a negative rate coefficient ($\beta = -0.7$) means that higher $x$ **increases the expected duration** by a factor of $e^{-\beta} = e^{+0.7} \approx 2.01$ ($+101\%$ longer waiting time).

---

## Key Takeaways

- For continuous positive waiting times and latencies ($y > 0$), use an **Exponential likelihood** with a **log link on the rate parameter** $\log(\lambda) = \alpha + \beta x$.
- A positive slope $\beta > 0$ increases the event rate $\lambda$, which **decreases the expected duration** $\mathbb{E}[y] = 1/\lambda$.
- For processes where the standard deviation varies independently of the mean, consider **Gamma** or **Lognormal** GLMs.
