# Comparing Mixed Models and Hierarchical Bayes

## 1. Two Philosophical Paradigms for Grouped Data

In experimental psychology, neuroscience, and medicine, repeated-measures datasets (e.g. longitudinal patient trials, trial-by-trial reaction times across subjects) are traditionally analyzed using **Linear Mixed-Effects Models (LMMs / GLMMs)** via software such as `lme4` in R or `statsmodels.MixedLM` in Python.

In modern computational statistics, **Hierarchical Bayesian Modeling** (via `PyMC` and `Bambi`) generalizes mixed models into a fully generative probabilistic framework:

| Dimension | Classical Mixed Models (`lme4` / `statsmodels`) | Hierarchical Bayesian MCMC (`PyMC` / `Bambi`) |
|---|---|---|
| **Estimation Method** | Maximum Likelihood (REML / Laplace approx.) | Full Markov Chain Monte Carlo (NUTS / HMC) |
| **Variance Components ($\tau$)** | Single point estimate $\hat{\tau}$; standard errors often unavailable | Full posterior distribution $p(\tau \mid y)$ |
| **Singular Fit Boundary ($\hat{\tau} = 0$)** | Prone to collapsing onto boundary ($\tau^2 = 0$) in small samples | Scale priors (HalfNormal/Exponential) prevent collapse |
| **Random Effects ($u_j$)** | Conditional modes (BLUPs) without joint uncertainty | True latent parameters with exact credible intervals |
| **Model Comparison** | AIC / BIC / Likelihood Ratio Tests (LRT) | Out-of-sample predictive accuracy (**PSIS-LOO**) |

## 2. Case Study 1: The Sleep Deprivation Experiment (`sleepstudy`)

In the classic Belenky et al. (2003) sleep deprivation study, $N = 18$ subjects were restricted to 3 hours of sleep per night for 10 consecutive days (`Days` 0 to 9), and their average reaction time (`Reaction` in ms) was measured daily.

### Model Formulation: Varying Intercepts and Varying Slopes
$$
y_{ij} \sim \operatorname{Normal}(\mu_{ij}, \sigma), \quad \mu_{ij} = (\alpha_0 + u_{\alpha, j}) + (\beta_0 + u_{\beta, j}) \cdot \text{Days}_{ij}
$$
where the subject-specific random effects follow a bivariate Normal distribution with correlation $\rho$:

$$
\begin{bmatrix} u_{\alpha, j} \\ u_{\beta, j} \end{bmatrix} \sim \operatorname{Normal}\left(\begin{bmatrix} 0 \\ 0 \end{bmatrix}, \begin{bmatrix} \tau_\alpha^2 & \rho \tau_\alpha \tau_\beta \\ \rho \tau_\alpha \tau_\beta & \tau_\beta^2 \end{bmatrix}\right)
$$

## 3. High-Level Implementation: Bambi vs. Statsmodels

### Classical Mixed Model in Statsmodels / lme4
```python
import statsmodels.formula.api as smf

# Frequentist MixedLM with random intercept and slope
lm_mixed = smf.mixedlm(
    "Reaction ~ Days", 
    data=sleep_df, 
    groups=sleep_df["Subject"], 
    re_formula="~ Days"
).fit()

print(lm_mixed.summary())
```

### Hierarchical Bayesian Model in Bambi / PyMC
```python
import bambi as bmb
import arviz as az

# Bayesian formula specification matching lme4 syntax
model_sleep = bmb.Model(
    "Reaction ~ Days + (Days | Subject)", 
    data=sleep_df
)

idata_sleep = model_sleep.fit(draws=2000, tune=1000, target_accept=0.95)

# Posterior summary including variance components and correlations
az.summary(idata_sleep, var_names=["Days", "Subject|Days", "sigma"])
```

## 4. Case Study 2: Longitudinal Binary Data (Depression Drug Trial)

In longitudinal clinical trials where binary patient outcomes ($y \in \{0, 1\}$: normal vs abnormal depression score) are tracked over time ($t \in \{0, 1, 2\}$) across drug treatment arms, classical logistic GLMMs frequently encounter numerical integration errors.

In Bayesian workflow, we specify a **Hierarchical Logistic Regression Model**:

```python
# Hierarchical Logistic GLMM in Bambi
model_depr = bmb.Model(
    "outcome ~ drug * time + severity + (1 | case)",
    data=depression_df,
    family="bernoulli"
)

idata_depr = model_depr.fit(draws=2000, tune=1000, target_accept=0.95)

# Compare with flat model via PSIS-LOO
cmp = az.compare({
    "Single-Level Logistic": idata_flat,
    "Hierarchical Patient Model": idata_depr
})
print(cmp)
```

## 5. When Should You Choose Hierarchical Bayes Over Classical Mixed Models?

1. **Small Cluster Counts ($J < 15$)**: Classical REML estimates of $\tau^2$ are heavily biased downward when cluster sizes are small. Bayesian MCMC propagates full hyperparameter uncertainty.
2. **Singular Fit Warnings in `lme4`**: When `lme4` throws `boundary (singular) fit: see ?isSingular`, it means the optimization converged to $\tau = 0$. Bayesian priors prevent variance collapse.
3. **Non-Gaussian Likelihoods with Complex Random Effects**: GLMM Laplace approximations can fail under sparse binary or count data; MCMC provides exact finite-sample inference.
4. **Rankings and Substantive Predictions**: Hierarchical Bayes produces complete posterior distributions for individual cluster ranks and counterfactual interventions.

---

## Key Takeaways

- Hierarchical Bayes shares the **exact same model structure** as classical mixed-effects models (`lme4`), but estimates parameters via **full joint posterior integration** instead of point-optimization.
- The **LKJ Cholesky prior** allows robust estimation of correlation parameters $\rho$ between varying intercepts and slopes.
- Use **Bambi** for seamless formula-based modeling that automatically translates `lme4` syntax into robust PyMC probabilistic graphs.
