## 1. The Generative Modeling Workflow

A statistical model in Bayesian analysis is not a passive curve-fitting formula; it is an active **generative hypothesis** about how observable empirical phenomena are produced in nature or society.

Before estimating parameters from real data, an analyst should be able to run the model *forward* as a computer simulation. If the synthetic data produced by the model looks completely unrealistic (e.g. negative reaction times, impossible survey percentages, or counts without variability), the model is flawed before any data fitting begins.

## 2. Parameters, Observations and Conditioning

Every statistical model operates across two distinct domains:

| Entity | Symbol | Domain | Epistemic Status | Examples |
|:---|:---:|:---:|:---|:---|
| **Latent Parameters** | $\theta, \mu, \beta, \sigma$ | Parameter Space $\Theta$ | **Unobservable**. Fixed constants of nature or population properties that we seek to learn. | True population support rate, cognitive processing speed, causal effect. |
| **Observed Data** | $y = (y_1, \dots, y_N)$ | Data Space $\mathcal{Y}$ | **Observed**. Fixed, recorded empirical numbers. | Survey responses, reaction times in ms, test scores. |
| **Future Observations** | $\tilde{y}$ | Data Space $\mathcal{Y}$ | **Unobserved**. Observable quantities we anticipate seeing in future replications. | Next patient outcome, tomorrow's poll result. |

## 3. Canonical Discrete Data-Generating Processes

### 1. The Bernoulli and Binomial Process (Binary & Proportion Data)
When observing independent binary events (e.g. voter choice, correct/incorrect cognitive trials):

* **Bernoulli Trial**: A single event with success parameter $\theta \in [0, 1]$:

$$
\mathbb{P}(y \mid \theta) = \theta^y (1 - \theta)^{1 - y}, \quad y \in \{0, 1\}
$$

* **Binomial Process**: The total number of successes $k = \sum_{i=1}^N y_i$ out of $N$ independent trials:

$$
\mathbb{P}(k \mid N, \theta) = \binom{N}{k} \theta^k (1 - \theta)^{N - k}, \quad k \in \{0, 1, \dots, N\}
$$

  * **Expected Value**: $\mathbb{E}[k] = N\theta$
  * **Variance**: $\text{Var}(k) = N\theta(1 - \theta)$

### 2. The Poisson Process (Count Events & Rates)
When counting events occurring in a fixed interval or spatial unit with constant intensity rate $\lambda > 0$:

$$\mathbb{P}(y \mid \lambda) = \frac{\lambda^y e^{-\lambda}}{y!}, \quad y \in \{0, 1, 2, \dots\}$$

* **Equi-dispersion Property**: $\mathbb{E}[y] = \text{Var}(y) = \lambda$.
* **Overdispersion Diagnostic**: In real-world social and cognitive data, unobserved heterogeneity causes empirical variance to exceed the mean ($\text{Var}(y) > \mathbb{E}[y]$). This signals that a simple Poisson process is inadequate and requires a **Negative Binomial** mixture model.

## 4. Likelihood as a Compatibility Function

Once data $y = k$ has been recorded in an experiment or survey, the data is fixed. The **Likelihood Function** $\mathcal{L}(\theta \mid y)$ treats the data as fixed and evaluates the relative plausibility of different candidate values of the parameter $\theta$:

$$\mathcal{L}(\theta \mid y = k) \equiv p(y = k \mid \theta) = \binom{N}{k} \theta^k (1 - \theta)^{N - k}$$

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       WHAT IS A LIKELIHOOD FUNCTION?                        │
│ ─────────────────────────────────────────────────────────────────────────── │
│ 1. It is a function of the PARAMETER θ, evaluated for fixed data y.         │
│ 2. It ranks how compatible each parameter value is with the observed data.  │
│ 3. The peak of the function is the Maximum Likelihood Estimate (MLE):       │
│                               θ_hat = k / N                                 │
│ 4. It is NOT a probability distribution over θ (its integral ≠ 1).          │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. The Bayesian Quartet: Four Fundamental Distributions

In Bayesian analysis, there are four distinct distributions that must never be conflated:

| Distribution | Mathematical Definition | Space | Conceptual Meaning |
|:---|:---|:---:|:---|
| **1. Prior Distribution** | $p(\theta)$ | Parameter Space $\Theta$ | Initial epistemic uncertainty about parameters *before* seeing data. |
| **2. Prior Predictive Distribution** | $p(y_{\text{sim}}) = \int p(y_{\text{sim}} \mid \theta) p(\theta) d\theta$ | Data Space $\mathcal{Y}$ | What observable data the model expects to generate *before* data collection. |
| **3. Posterior Distribution** | $p(\theta \mid y) = \frac{p(y \mid \theta)p(\theta)}{p(y)}$ | Parameter Space $\Theta$ | Updated epistemic uncertainty about parameters *after* conditioning on data $y$. |
| **4. Posterior Predictive Distribution** | $p(\tilde{y} \mid y) = \int p(\tilde{y} \mid \theta) p(\theta \mid y) d\theta$ | Data Space $\mathcal{Y}$ | Anticipated future observations $\tilde{y}$ accounting for both parameter uncertainty and residual aleatory noise. |

---

## 6. Reducible (Epistemic) vs. Irreducible (Aleatory) Uncertainty

A foundational distinction in generative modeling:

* **Reducible Uncertainty (Epistemic / Parameter Knowledge)**: Uncertainty arising from our **lack of data or knowledge** about the true parameter value $\theta$. As sample size grows ($N \to \infty$), reducible uncertainty shrinks to zero.
* **Irreducible Uncertainty (Aleatory / Process Scatter)**: Inherent physical, behavioral, or trial-by-trial randomness in the data-generating process. Even if we know the true parameter $\theta = 0.65$ with 100% precision, an individual coin flip or survey respondent still fluctuates stochastically.

:::{important}
The **Expected Outcome** $\mathbb{E}[\tilde{y} \mid \theta] = N\theta$ is a function of the parameter (governed by reducible uncertainty).  
An **Observable Realization** $\tilde{y} \sim \text{Binomial}(N, \theta)$ contains irreducible dispersion around the expected outcome.
:::

## 7. Fake-Data Simulation Workflow

Before fitting models to empirical datasets, write a minimal 10-line simulation to verify your model logic:

```python
import numpy as np

# 1. Set seed for deterministic reproducibility
rng = np.random.default_rng(2026)

# 2. Define true generative parameters
true_theta = 0.65  # True support proportion
n_sample = 20      # Sample size per survey
n_reps = 1_000     # Number of simulated survey replications

# 3. Forward generate synthetic survey observations
simulated_surveys = rng.binomial(n=n_sample, p=true_theta, size=n_reps)

# 4. Check generative properties
print(f"Theoretical Mean: {n_sample * true_theta:.2f}")
print(f"Simulated Mean:   {np.mean(simulated_surveys):.2f}")
print(f"Simulated 95% Interval: [{np.percentile(simulated_surveys, 2.5):.0f}, {np.percentile(simulated_surveys, 97.5):.0f}]")
```

````{dropdown} 📝 Exercise 1: Computing Binomial Likelihood Ratios (Click to expand solution)
**Question**: An opinion poll surveys $N = 20$ citizens and observes $k = 13$ supporters of a policy. 
1. Compute the exact likelihood of the observed data under hypothesis $H_1: \theta = 0.65$ and under hypothesis $H_2: \theta = 0.50$.
2. Calculate the Likelihood Ratio $\text{LR} = \frac{\mathcal{L}(\theta = 0.65 \mid k=13)}{\mathcal{L}(\theta = 0.50 \mid k=13)}$.

**Solution & Step-by-Step Calculation**:

1. **Binomial Likelihood Computations**:

   Under hypothesis $H_1: \theta = 0.65$:

$$
\mathcal{L}(\theta = 0.65 \mid k=13) = \binom{20}{13} (0.65)^{13} (0.35)^7 \approx 77{,}520 \times 0.003700 \times 0.000643 \approx \mathbf{0.1844}
$$

   Under hypothesis $H_2: \theta = 0.50$:

$$
\mathcal{L}(\theta = 0.50 \mid k=13) = \binom{20}{13} (0.50)^{13} (0.50)^7 = 77{,}520 \times (0.50)^{20} = \frac{77{,}520}{1{,}048{,}576} \approx \mathbf{0.0739}
$$

2. **Likelihood Ratio (Relative Compatibility)**:

$$
\text{LR} = \frac{\mathcal{L}(\theta = 0.65 \mid k=13)}{\mathcal{L}(\theta = 0.50 \mid k=13)} = \frac{0.1844}{0.0739} \approx \mathbf{2.495}
$$
````

````{dropdown} 📝 Exercise 3: Diagnosing Poisson Overdispersion (Click to expand solution)
**Question**: A cognitive psychologist records the number of errors made by participants on a complex visual search task over 100 trials. The sample mean error count is $\bar{y} = 4.0$, but the sample variance is $s^2 = 12.0$.
1. Why does this violate a standard Poisson generative process?
2. What physical/cognitive mechanism could explain this overdispersion?

**Solution**:
1. **Theoretical Violation**: A Poisson process has the strict mathematical property of **equi-dispersion**: $\text{Var}(Y) = \mathbb{E}[Y] = \lambda$. Here, the sample variance ($12.0$) is three times larger than the mean ($4.0$), representing severe overdispersion ($\text{Dispersion Index} = 12.0 / 4.0 = 3.0$).
2. **Substantive Mechanism**: Individual participants do not share a single constant error rate $\lambda$. Differences in fatigue, attention lapses, visual acuity, and strategy create **latent rate heterogeneity** ($\lambda_i \sim \text{Gamma}(\alpha, \beta)$). When rates vary across participants, the resulting compound distribution is Negative Binomial with variance $\text{Var}(Y) = \mu + \frac{\mu^2}{\alpha} > \mu$.
````

## 9. Concept Check

````{dropdown} ❓ What is the difference between the posterior distribution and the posterior predictive distribution?
The **posterior distribution** $p(\theta \mid y)$ lives in parameter space and quantifies our updated uncertainty about unobservable parameters $\theta$. The **posterior predictive distribution** $p(\tilde{y} \mid y)$ lives in data space and quantifies what observable outcomes $\tilde{y}$ we anticipate in future replications, incorporating both parameter uncertainty and residual aleatory noise.
````

````{dropdown} ❓ If sample size N → ∞, does the posterior predictive distribution become a single point?
**No.** As $N \to \infty$, epistemic uncertainty about the parameter vanishes ($p(\theta \mid y) \to \delta(\theta - \theta_0)$), but future individual observations $\tilde{y}$ still follow the stochastic data-generating process $p(\tilde{y} \mid \theta_0)$ with irreducible aleatory variance.
````

````{dropdown} ❓ Why do we simulate fake data before observing real data?
Fake-data simulation tests whether the model's mathematical assumptions produce plausible data under known parameter truths. It verifies software code, tests parameter recovery, and identifies impossible model implications before empirical fitting.
````
