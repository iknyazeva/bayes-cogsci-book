# Bayesian Estimation of Group Differences (The BEST Model)

## 1. Limitations of the Classical Student's $t$-Test

In classical experimental psychology and empirical research, the two-sample Student's $t$-test is the standard default for comparing two groups. However, the classical $t$-test suffers from three severe structural vulnerabilities:
1. **The Normality Assumption**: It assumes data in both groups are Gaussian. Valid extreme values or outliers skew the sample means and artificially inflate the standard errors.
2. **The Equal Variance (Homoskedasticity) Trap**: Standard $t$-tests assume $\sigma_1 = \sigma_2$. While Welch's $t$-test relaxes this, it offers no direct posterior probability distribution for the variance ratio.
3. **The Dichotomous $p$-Value Trap**: A $p$-value ($p < 0.05$) only indicates whether a point null hypothesis ($H_0: \mu_1 = \mu_2$) can be rejected; it provides **zero information about the magnitude of the difference**, the precision of the estimate, or whether the difference is practically negligible.

To overcome these limitations, John Kruschke (2013) developed **BEST (Bayesian Estimation Supersedes the $t$-Test)**.

---

## 2. The BEST Generative Model

Instead of testing a binary null hypothesis, BEST estimates the full joint posterior distribution over five parameters:
- **Group Locations**: $\mu_1, \mu_2$
- **Group Scales**: $\sigma_1, \sigma_2$ (allowing unequal variances)
- **Normality / Tail Parameter**: $\nu$ (a shared degrees-of-freedom parameter)

$$
y_{i, 1} \sim t_\nu(\mu_1, \sigma_1), \quad y_{i, 2} \sim t_\nu(\mu_2, \sigma_2)
$$

```
               Data Generating Structure (BEST)
               
                 [ ν ~ Exp(1/29) + 1 ]
                       /       \
                      /         \
        [ μ₁ ~ Normal ]         [ μ₂ ~ Normal ]
        [ σ₁ ~ HalfNormal ]     [ σ₂ ~ HalfNormal ]
               |                       |
               v                       v
      y₁,ᵢ ~ t_ν(μ₁, σ₁)      y₂,ᵢ ~ t_ν(μ₂, σ₂)
```

### Scale-Calibrated Prior Specification
Priors are calibrated to the combined data mean $\bar{y}_{\text{pool}}$ and standard deviation $s_{\text{pool}}$:
- $\mu_1, \mu_2 \sim \operatorname{Normal}(\bar{y}_{\text{pool}}, \, 2 \cdot s_{\text{pool}})$
- $\sigma_1, \sigma_2 \sim \operatorname{HalfNormal}(2 \cdot s_{\text{pool}})$
- $\nu - 1 \sim \operatorname{Exponential}(\lambda = 1/29)$ *(concentrating mass around $\nu \approx 30$ for Gaussian baseline, while allowing heavy tails if outliers exist)*.

---

## 3. Substantive Contrasts on the Observable Scale

From the joint posterior draws, we compute three derived quantities:

1. **Difference of Means**: $\Delta \mu = \mu_1 - \mu_2$
2. **Difference of Standard Deviations**: $\Delta \sigma = \sigma_1 - \sigma_2$
3. **Effect Size (Bayesian Cohen's $d$)**:

$$
d = \frac{\mu_1 - \mu_2}{\sqrt{\frac{\sigma_1^2 + \sigma_2^2}{2}}}
$$

## 4. Decision Making: The HDI + ROPE Framework

To make principled substantive decisions without $p$-values, Kruschke introduced the **Region of Practical Equivalence (ROPE)** combined with the **95% Highest Density Interval (HDI)**:

- **Define a ROPE**: A domain-specific band around zero (e.g., $[-0.2, 0.2]$) where differences are considered practically negligible.
- **Decision Rules**:
  1. **Reject Null (Meaningful Effect)**: If the 95% HDI of $\Delta \mu$ falls **entirely outside the ROPE** (e.g., $[1.5, 2.7]$).
  2. **Accept Null (Practical Equivalence)**: If the 95% HDI falls **entirely inside the ROPE** (e.g., $[-0.05, 0.08]$).
  3. **Undecided (Collect More Data)**: If the 95% HDI overlaps the boundaries of the ROPE.

```python
import pymc as pm
import arviz as az

with pm.Model() as best_model:
    # 1. Priors calibrated to pooled data
    mu_pool = df["value"].mean()
    sigma_pool = df["value"].std() * 2.0
    
    mu = pm.Normal("mu", mu=mu_pool, sigma=sigma_pool, shape=2)
    sigma = pm.HalfNormal("sigma", sigma=sigma_pool, shape=2)
    nu = pm.Exponential("nu_minus_one", 1/29.0) + 1.0
    
    # 2. Likelihood with group indexing
    y_obs = pm.StudentT("y_obs", nu=nu, mu=mu[df["group_id"]], sigma=sigma[df["group_id"]], observed=df["value"])
    
    # 3. Deterministic Contrasts
    diff_means = pm.Deterministic("diff_means", mu[0] - mu[1])
    diff_sigmas = pm.Deterministic("diff_sigmas", sigma[0] - sigma[1])
    cohen_d = pm.Deterministic("cohen_d", diff_means / pm.math.sqrt((sigma[0]**2 + sigma[1]**2)/2.0))
    
    idata_best = pm.sample(draws=2000, tune=1000, target_accept=0.95)

# Plot posterior with ROPE
az.plot_posterior(idata_best, var_names=["diff_means", "cohen_d"], rope=[-0.2, 0.2], hdi_prob=0.95)
```

## Key Takeaways

- BEST replaces the rigid assumptions of the classical $t$-test with a **Student-$t$ likelihood**, protecting inferences from outliers and permitting unequal variances ($\sigma_1 \neq \sigma_2$).
- The parameter $\nu$ lets the data dictate whether error distributions are light-tailed ($\nu > 30$) or heavy-tailed ($\nu < 10$).
- Use the **HDI + ROPE framework** to distinguish true substantial effects, practical equivalence, and statistical indeterminacy.
